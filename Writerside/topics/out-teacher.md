# 외출 신청 승인

교사는 외출·취식·특별실 신청 목록 또는 메시지로 받은 신청 자료에서 승인 작업을 수행합니다.

## 목록에서 승인

1. 교사용 **외출 신청** 화면을 엽니다.
2. 날짜, 상태 또는 학생으로 대상을 찾습니다.
3. 신청 종류, 시간, 사유와 참가자를 확인합니다.
4. **승인**을 선택하고 상태 변경을 확인합니다.

## 메시지에서 승인

학생이 신청서를 메시지 자료로 보낸 경우 자료를 열어 상세 내용을 확인합니다. 화면에 승인 작업이 표시되면 같은 방식으로 처리할 수 있습니다.

<warning>
참가자가 여러 명인 신청은 전체 명단을 확인하세요. 승인 전후의 실제 외출 가능 여부는 학교 운영 절차를 따릅니다.
</warning>
