# 메시지

학생, 교사, 관리자와 학부모는 허용된 상대와 1:1 메시지를 주고받을 수 있습니다. 졸업생 계정에는 메시지 기능이 제공되지 않습니다.

## 새 대화 시작

1. **메시지**에서 새 대화를 선택합니다.
2. 이름이나 계정 정보로 상대를 검색합니다.
3. 내용을 입력하고 필요하면 파일이나 자료를 첨부합니다.
4. 수신자를 다시 확인한 뒤 전송합니다.

학생은 다른 학생에게 새 대화를 시작할 수 없습니다. 교직원 등 화면에 표시되는 허용 대상만 선택할 수 있습니다.

## 대화 관리

- 대화 목록과 내용 검색
- 메시지 읽음 상태 확인
- 파일, 게시글 또는 외출 신청 자료 열기
- 자신이 보낸 메시지 삭제

<note>
보낸 메시지를 삭제해도 상대가 이미 확인하거나 별도로 저장한 내용까지 회수되는 것은 아닙니다.
</note>

교사·관리자의 여러 명 대상 발송은 [](batch-messages.md)을 참고하세요.
