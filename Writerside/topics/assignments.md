# 과제 센터와 제출

학생은 과제 센터에서 일반 과제와 연결된 Google Classroom 과제를 함께 확인하고 제출합니다.

## 과제 찾기

1. **과제 센터**로 이동합니다.
2. 상태, 수업 또는 마감 조건으로 필터링합니다.
3. 제목을 검색하거나 과제 카드를 엽니다.
4. 설명, 마감, 첨부 자료와 제출 상태를 확인합니다.

## 제출하기

1. 과제 상세에서 **제출**을 선택합니다.
2. 파일, 링크, 텍스트, Google Drive 또는 Google Docs 자료를 추가합니다.
3. 제출 내용을 확인하고 완료합니다.
4. 상태가 제출 완료로 바뀌었는지 확인합니다.

허용되는 동안 제출을 취소하거나 수정해 다시 제출할 수 있습니다. 제출 기록에서 이전 버전과 교사의 점수·피드백을 확인하세요.

온라인 저지 과제는 파일 대신 본인이 제출한 온라인 저지 결과를 선택해 연결합니다.

<warning>
과제 제출 기록의 첨부파일은 14일 뒤 만료될 수 있습니다. 제출 원본과 중요한 피드백은 별도로 보관하세요.
</warning>

교사용 관리 방법은 [](assignment-management.md)을 참고하세요.
