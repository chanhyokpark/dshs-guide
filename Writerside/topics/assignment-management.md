# 과제 관리와 채점

교사와 관리자는 **과제 관리**에서 여러 게시판·수업의 과제를 모아 보고 제출을 채점합니다.

## 과제 목록

제목 검색, 게시판 필터와 최근 게시·마감순 정렬을 사용합니다. 각 과제에는 제출 수, 채점 필요 수와 지각 제출 요약이 표시됩니다. 과제를 선택하면 학생별 관리 화면이 열립니다.

## 제출 목록

- 이름·학번 검색
- 분반 필터
- 전체, 제출, 미제출 상태 필터
- 학번, 이름, 제출 시각 또는 점수 정렬
- 제출 첨부파일을 화면 안에서 미리보기

목록의 학생을 선택하면 오른쪽 채점 패널에서 이전·다음 학생으로 이동할 수 있습니다.

## 개인 채점

1. 현재 제출과 제출 이력을 확인합니다.
2. 점수, 글 피드백과 피드백 첨부파일을 입력합니다.
3. 필요한 경우 학생별 마감 조정 등 화면에 제공되는 예외 설정을 확인합니다.
4. 저장하고 다음 학생으로 이동합니다.

첨부 제출이 없어도 교사가 완료 상태와 점수를 기록할 수 있습니다. **채점 취소**는 저장된 점수·피드백을 제거하므로 다시 채점할 때만 사용하세요. 메시지 버튼으로 해당 학생에게 1:1 대화를 시작할 수 있습니다.

## 일괄 채점

- 화면에 학번, 점수와 피드백 행을 직접 붙여 넣기
- 제공되는 Google 스프레드시트 템플릿으로 작성 후 반영
- 이전 일괄 채점 작업의 결과와 오류 상세 확인

반영 전에 학생 식별자와 점수 범위를 검증합니다. 오류 행이 있으면 결과 화면에서 해당 학생을 확인하고 수정한 자료로 다시 실행하세요.

## 성적과 제출 파일 내보내기

- 과제 점수표 내보내기
- 일반 과제의 모든 제출 파일을 ZIP으로 묶기
- 파일명을 학번·이름으로 바꾸거나 학생별 폴더로 정리
- 생성 요청의 처리 상태와 과거 요청 확인

온라인 저지 과제는 일반 제출 파일 ZIP 대상이 아닙니다. 생성된 ZIP과 제출 이력의 파일은 **14일 후 만료**되므로 필요한 자료는 즉시 안전한 위치에 저장하세요.
