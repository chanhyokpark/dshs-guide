# 과제 관리와 채점

교사와 관리자는 과제 목록에서 제출 상태를 확인하고 개인 또는 일괄 채점을 수행합니다.

## 제출 확인과 개인 채점

1. 과제 관리에서 상태·수업·마감 필터를 적용합니다.
2. 과제를 미리 보고 제출 목록을 엽니다.
3. 학생의 제출 기록과 첨부파일을 확인합니다.
4. 점수와 피드백을 입력하고 필요하면 피드백 파일을 첨부합니다.
5. 저장 후 학생에게 표시되는 상태를 확인합니다.

필요한 경우 채점을 취소한 뒤 다시 채점할 수 있습니다.

## 일괄 채점과 내보내기

- 화면에서 여러 제출에 점수를 직접 입력
- Google 스프레드시트로 채점 자료를 주고받기
- 성적 결과 내보내기
- 일반 과제 제출 파일을 ZIP으로 내려받기

온라인 저지 과제는 제출 파일 ZIP 대상이 아닙니다. 생성된 제출 파일 보관본은 14일 뒤 만료될 수 있으므로 필요한 경우 즉시 안전한 위치로 옮기세요.

<warning>
일괄 반영 전 학생 식별자와 행 대응을 확인하세요. 스프레드시트의 열 이름이나 식별자를 임의로 변경하면 잘못된 학생에게 반영될 수 있습니다.
</warning>
