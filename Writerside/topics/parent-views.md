# 학생별 읽기 전용 화면

학부모 홈에서 연결된 학생을 선택하면 해당 학생의 학교생활 정보를 읽기 전용으로 확인할 수 있습니다.

## 확인 가능한 항목

- 자습 신청과 좌석 현황
- 외출·특별실 신청 상태
- 상·벌점 합계와 기록
- 급식과 알레르기 정보

학부모 계정으로 학생 대신 신청·취소·과제 제출을 할 수 없습니다. 과제, 온라인 저지, 학교 Google 연동과 학생 프로필 변경 기능도 제공되지 않습니다.

게시판의 글·댓글·즐겨찾기·구독과 메시지는 학부모 본인 계정의 권한으로 사용합니다.

<tip>
학생이 여러 명이면 화면 상단의 선택된 학생 이름을 확인한 뒤 내용을 보세요.
</tip>
