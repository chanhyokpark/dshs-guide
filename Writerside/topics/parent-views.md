# 자녀 학교생활 확인

학부모 홈에서 현재 선택한 자녀의 자습, 외출·특별실과 상·벌점 정보를 읽기 전용으로 확인합니다. 자녀가 여러 명이면 화면 상단의 학생 선택 메뉴에서 전환합니다.

## 학부모 홈

홈에는 선택한 자녀의 주요 학교생활 카드와 학부모 계정의 최근 메시지가 표시됩니다. 빠른 실행으로 외출 현황, 게시판, 설정과 급식으로 이동할 수 있습니다.

페이지를 이동한 뒤에도 선택한 학생이 유지되지만, 정보를 보기 전에 이름을 다시 확인하는 것이 안전합니다.

## 자습 현황

[](reserve.md)의 날짜 화면에서 자녀의 오늘·다음 좌석과 전체 좌석 현황을 확인합니다. 좌석 검색과 과거 현황은 사용할 수 있지만 다음 동작은 할 수 없습니다.

- 좌석 신청·변경·취소
- 다른 학생과 자리 바꾸기
- 신청 연습을 실제 신청으로 반영

## 외출·특별실 현황

[](out.md)에서 자녀가 작성하거나 참여한 진행 중·종료 신청을 확인합니다. 유형, 장소, 기간, 승인 상태와 참여자 명단을 볼 수 있지만 신청 작성·수정·삭제, 참여·나가기와 승인 요청은 할 수 없습니다.

## 상·벌점

[](penalty-rules.md)에서 자녀의 받은 벌점, 받은 상점, 유효 점수, 그래프와 개별 기록을 확인합니다. 여러 자녀가 연결되어 있으면 상·벌점 화면의 학생 선택 메뉴로도 바꿀 수 있습니다.

## 급식

급식은 계정 공통 정보이며 자녀별로 달라지지 않습니다. 날짜 이동과 알레르기 강조는 [](meal.md)을 참고하세요.

학부모 계정에는 학생 대신 하는 기숙사 신청, 과제 센터, 온라인 저지, 도서관 바코드와 학생 프로필 수정 기능이 제공되지 않습니다.
