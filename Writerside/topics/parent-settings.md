# 학부모 설정과 학생 관리

학부모 설정에는 일반, 학생 관리, 알림과 사이트 정보가 표시됩니다. 학생·교사용 프로필, 급식·자습·외출 표시 설정과 Google 계정 연결은 제공되지 않습니다.

## 학생 전환

연결 학생이 여러 명이면 홈과 지원되는 학교생활 화면의 학생 선택 메뉴로 현재 학생을 바꿉니다. 선택 상태는 브라우저에 유지됩니다. 자녀 이름과 학번을 확인한 뒤 정보를 읽으세요.

## 학생 추가

1. <ui-path>설정 | 학생 관리</ui-path>를 엽니다.
2. 4자리 학번, 이름과 학부모 인증 코드를 입력합니다.
3. **학생 추가**를 누릅니다.
4. 목록에 나타난 학번과 이름을 확인합니다.

이미 다른 학부모 계정에 연결된 학생이면 기존 계정 삭제 경고가 표시됩니다. 계속하면 기존 계정 전체가 더 이상 사용할 수 없게 되므로 [](parent-registration.md)의 주의사항을 확인하세요.

## 연결 해제

학생 목록에서 연결 해제를 누르면 그 학생의 정보를 더 이상 볼 수 없습니다. 다시 연결하려면 인증 코드가 필요합니다. 계정에는 최소 한 명의 학생이 연결되어 있어야 하므로 마지막 학생은 해제할 수 없습니다.

## 일반

- 패스키 목록 확인, 추가와 삭제
- 로그인 인증 코드를 받을 이메일 변경
- 홍보 배너 위치 선택
- 현재 브라우저에 저장된 설정 초기화

패스키를 사이트에서 삭제한 뒤에는 비밀번호 관리자에서도 수동으로 삭제해야 합니다. 이메일 변경은 새 주소로 받은 인증 코드를 입력해야 완료됩니다.

## 알림과 사이트 정보

알림 항목을 선택해 저장하고 iOS·Android 시스템 알림 권한도 확인합니다. 사이트 정보에서는 현재 웹 버전과 제작자 정보를 확인합니다.
