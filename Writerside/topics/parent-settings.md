# 학부모 설정과 사용자 관리

로그인 Account의 설정과 현재 학부모 User의 설정은 서로 다릅니다.

- **Account:** 로그인 이메일, 비밀번호, 패스키, 로그인 기기, 연결된 사용자
- **User:** 현재 자녀에 해당하는 학부모 역할, 게시판·신청·벌점 기록, 알림 설정

## 자녀 전환

학생 한 명마다 `학생이름 학부모` User가 하나씩 있습니다. 자녀가 여러 명이면 홈이나 학교생활 화면의 학생 선택기가 아니라 상단 계정 메뉴의 **사용자 전환**을 사용합니다.

1. 화면 상단의 현재 사용자 이름을 누릅니다.
2. **사용자 전환** 목록에서 확인할 자녀의 `학생이름 학부모`를 선택합니다.
3. 헤더의 현재 사용자 이름이 바뀌었는지 확인한 뒤 자습·벌점·게시판 등을 엽니다.

전환은 로그아웃하지 않고 현재 세션의 User만 바꿉니다. 알림이나 링크를 열 때 대상 User로 자동 전환될 수도 있습니다.

## 다른 자녀 추가

1. [계정 설정](https://auth.dshs.app/settings/account)을 엽니다.
2. **연결된 사용자 | 다른 사용자 추가**를 누릅니다.
3. 새 자녀의 `parent-...@dshs.app` 등록 주소와 8자리 인증코드를 입력합니다.
4. 표시된 User와 필수 동의를 확인합니다.
5. **현재 계정에 연결**을 누릅니다.
6. 상단 **사용자 전환**에서 새 학부모 User를 선택합니다.

자세한 등록 순서는 [](parent-registration.md)을 참고하세요. 기존의 <ui-path>설정 | 학생 관리</ui-path> 화면과 학생 선택기는 더 이상 사용하지 않습니다.

## 계정 설정

[계정 설정](https://auth.dshs.app/settings/account)에서는 다음 항목을 관리합니다.

- 로그인 이메일 변경
- 비밀번호 설정·변경·삭제
- 패스키 목록 확인, 생성과 삭제
- 연결된 User 확인, 다른 User 추가와 연결 해제

현재 사용 중인 User는 다른 User로 먼저 전환해야 연결 해제할 수 있습니다. 마지막 User에서 **계정 삭제**를 선택하면 로그인 Account와 비밀번호·패스키·세션이 삭제됩니다. 학교 User와 기존 서비스 기록을 지우는 작업과는 구분됩니다.

[로그인 기기](https://auth.dshs.app/settings/sessions)에서는 계정으로 로그인된 브라우저와 앱을 확인하고 종료할 수 있습니다.

## 알림과 사이트 설정

DSHS.APP의 알림 설정은 현재 선택한 User에 저장됩니다. 여러 학부모 User가 연결되어 있으면 각 User로 전환해 원하는 알림 항목을 확인하세요.

급식 알레르기, 테마처럼 브라우저에 저장되는 일부 표시 설정은 Account나 User 데이터와도 별도로 현재 브라우저에 적용됩니다.
