# 알림과 구독

DSHS.APP 안의 알림 목록과 iOS·Android 푸시 알림은 서로 연결되어 있지만, 기기 알림 권한과 계정별 항목 설정이 모두 켜져야 푸시가 표시됩니다. macOS 앱 알림은 지원이 종료되었습니다.

## 알림 목록

상단의 종 모양 버튼을 누르면 최근 알림을 확인합니다. 알림 창을 열면 표시된 알림이 읽음 처리됩니다. **모두 삭제**는 현재 계정의 알림 목록을 비우므로 필요한 항목을 먼저 여세요.

## 계정별 알림 설정

<ui-path>설정 | 알림</ui-path>에서 다음 항목을 저장합니다.

| 항목 | 내용 | 기본값 |
|---|---|---|
| 필수 | 반드시 받아야 하는 운영 알림 | 항상 켜짐 |
| 자습 신청 정보 | 신청 시작 전 안내 | 켜짐 |
| 자리 바꾸기 요청 | 다른 학생의 자리 교환 요청 | **꺼짐** |
| 기숙사 신청 정보 | 신청하지 않았을 때 안내 | 켜짐 |
| 벌점/상점 | 상·벌점이 부여될 때 | 켜짐 |
| 외출 신청 | 참여, 승인 등 신청 관련 변경 | 켜짐 |
| 게시판 | 게시판·그룹 관련 알림 | 켜짐 |
| 과제 | 새 과제, 마감과 제출 관련 알림 | 켜짐·유지 권장 |
| 벌점 초과 메시지 | 학생이 징계 기준에 도달하면 System 계정 메시지 수신 | 교사·관리자만, **꺼짐** |

메시지 수신 자체는 메시지 메뉴에서 확인합니다. 게시판 알림을 켜더라도 알림을 받을 게시판 또는 글을 별도로 구독해야 할 수 있습니다.

## 게시판·글 구독

- 게시판 구독: 해당 게시판의 새 글 알림
- 개별 글 구독: 선택한 글의 댓글 등 후속 활동 알림
- 즐겨찾기: 홈과 목록에서 빨리 찾는 표시이며 구독과 별개

공지와 과제는 구독 여부와 무관하게 알림을 받습니다.

## 푸시가 오지 않을 때

1. 설정을 저장했는지 확인합니다.
2. iOS 또는 Android 시스템 설정에서 DSHS.APP 알림을 허용합니다.
3. Android의 배터리·백그라운드 제한을 확인합니다.
4. 앱이 최신 버전인지 확인하고 다시 로그인합니다.
