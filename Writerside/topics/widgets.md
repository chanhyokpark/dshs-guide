# iOS 위젯

iOS 앱은 홈 화면이나 잠금 화면에서 확인할 수 있는 상·벌점 위젯과 급식 위젯을 제공합니다.

## 위젯 종류

- 상·벌점 위젯: 현재 점수와 앱에 설정된 다음 단계까지의 정보를 표시
- 급식 위젯: 다음 급식 메뉴를 지원되는 크기로 표시

## 설치하기

1. iPhone 홈 화면의 빈 곳을 길게 누릅니다.
2. 위젯 추가 버튼을 선택합니다.
3. `대전과학고등학교` 또는 `DSHS.APP`을 검색합니다.
4. 원하는 위젯과 크기를 선택해 배치합니다.

데이터가 갱신되지 않으면 앱을 한 번 열고 로그인 상태와 네트워크를 확인하세요.

<note>
macOS 전용 앱과 위젯은 더 이상 제공하지 않습니다. Mac에서는 웹사이트를 사용하세요.
</note>
