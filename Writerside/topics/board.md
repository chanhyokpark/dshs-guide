# 게시판 찾기와 관리

게시판은 일반 글, 공지, 과제, 온라인 저지 문제와 여러 첨부 자료를 공유하는 공간입니다. 계정 역할뿐 아니라 각 게시판의 멤버·관리자 설정에 따라 보이는 기능이 달라집니다.

## 게시판 목록

- **즐겨찾기:** 별표를 켠 게시판
- **가입됨:** 내가 멤버인 게시판
- **관리:** 내가 관리자인 게시판
- **공개:** 멤버가 아니어도 볼 수 있는 게시판
- **전체:** 권한이 있는 교사·관리자에게 표시되는 전체 목록

이름으로 검색하고 별표를 눌러 즐겨찾기를 바꿉니다. 학생에게 학교 Google 계정이 연결되어 있으면 가져온 Classroom 수업도 함께 표시될 수 있습니다.

## 가입과 탈퇴

- 공개 게시판은 설정에 따라 바로 열거나 가입할 수 있습니다.
- **초대 코드**를 받은 경우 게시판 목록의 초대 코드 버튼에 입력합니다.
- 게시판 상세의 멤버 메뉴에서 허용된 사용자는 다른 사용자를 추가할 수 있습니다.
- 탈퇴하면 멤버 전용 글과 알림에 접근할 수 없게 됩니다. 다시 들어가려면 재초대 또는 유효한 코드가 필요합니다.

초대 코드는 게시판 접근 권한을 주므로 공개 채널에 올리지 마세요.

## 글 목록 사용

게시판은 **목록형** 또는 **Padlet형**으로 표시됩니다. 카테고리, 하위 게시판과 검색을 이용해 글을 찾습니다. 게시판 전체를 구독하면 새 글 알림을 받을 수 있으며, 공지와 과제는 게시판 구독 상태와 관계없이 알림 정책에 따라 전달될 수 있습니다.

즐겨찾기는 홈과 목록에서 빨리 찾기 위한 기능이고, 구독은 새 글 알림을 받는 기능이므로 서로 별개입니다.

## 게시판 만들기

권한이 있는 사용자는 **새 게시판**을 눌러 다음 방식으로 멤버를 정합니다.

- **그룹에서 만들기:** 기존 그룹 멤버를 게시판 멤버로 연결하고 게시판 관리자를 별도로 선택
- **사용자 직접 추가:** 관리자와 일반 멤버를 각각 선택
- **하위 게시판:** 상위 게시판 안에 만들며 멤버, 관리자와 일부 공개·초대 설정을 상위 게시판에서 상속

빠른 생성은 수업용 기본 설정을 적용합니다. 고급 설정에서는 카테고리와 아래 권한을 직접 정합니다.

| 설정 | 의미 |
|---|---|
| 게시판 공개 | 비회원도 게시글 열람 가능 |
| 댓글 허용 | 멤버가 댓글·답글 작성 가능 |
| 멤버 글쓰기 허용 | 일반 멤버의 새 글 작성 허용 |
| 비멤버 글쓰기 허용 | 멤버가 아닌 사용자도 작성 가능 |
| 멤버 초대 허용 | 일반 멤버도 사용자 초대 가능 |
| 초대 코드 사용 | 코드로 가입 가능 |
| 관리자 허락 전 게시물 숨기기 | 새 글을 관리자가 승인할 때까지 숨김 |
| 비밀 게시판 | 멤버만 접근하며 일반 관리자도 멤버가 아니면 볼 수 없음 |
| 좋아요 표시 | 게시글 좋아요 사용 |
| 싫어요 표시 | 좋아요와 함께 싫어요 사용 |

비밀 게시판을 켜면 공개 설정은 꺼집니다. 하위 게시판은 공개·비밀·허용 역할과 초대 관련 설정을 상위 게시판에서 상속하므로 하위 화면에서 바꿀 수 없습니다.

## 게시판 관리자

관리자는 이름·설명·표시 방식·카테고리·기본 카테고리와 권한 설정을 바꾸고, 멤버와 관리자를 관리하며 하위 게시판을 만들 수 있습니다. 공개 게시판에 교직원 접근이 허용된 경우 교사가 관리자로 참여하는 선택지가 표시될 수도 있습니다.

게시판 삭제는 모든 게시글과 댓글을 영구 삭제합니다. 삭제 전에 필요한 자료와 하위 게시판의 영향을 확인하세요. 서비스 전체 관리자의 일괄 운영은 [](admin-content.md)을 참고하세요.
