# 자습·기숙사 신청 운영

관리자는 날짜별 신청 가능 여부를 열고 닫으며 자습 신청 시간·대상·좌석과 공지를 관리합니다.

## 장소 신청 관리

상단 상태에는 실시간 신청 시스템의 활성·비활성 여부, 활성 날짜와 현재 공지가 표시됩니다. 달력의 기본 시간은 적용일 **전날 21:00~23:00**입니다.

### 날짜와 시간

1. 달력에서 날짜를 선택합니다.
2. **날짜 활성화**로 학생에게 신청 날짜를 엽니다.
3. 필요하면 시작·종료 시와 분을 변경합니다. 시간은 적용일 전날 기준입니다.
4. 신청이 끝난 뒤 상태와 확정 여부를 확인합니다.

진행 중 날짜를 비활성화하면 모든 클라이언트 연결이 끊기고 진행 중 신청 데이터가 삭제됩니다. 확정된 날짜는 일반 날짜처럼 비활성화하거나 시간을 바꿀 수 없습니다.

### 활성 사용자

**활성 사용자 > 편집**에서 이번 신청에 참여할 사용자를 선택합니다. 저장 전 `추가 N명/제거 N명` 차이를 확인할 수 있습니다. 신청 진행 중에도 변경할 수 있지만 별도 위험 확인 창이 표시됩니다.

### 수동 좌석 배정

1. 날짜를 선택하고 **좌석 수동 배정**을 엽니다.
2. 사용자 한 명을 선택합니다.
3. `a101`, `b205`, `s301` 같은 좌석명을 입력합니다.
4. 배정 성공 메시지와 실제 좌석 현황을 확인합니다.

### 수동 정리

신청 종료 후 **수동 정리**를 실행하면 미신청 사용자에게 벌점을 부여하고 자동 좌석 배정을 수행하며 날짜를 확정합니다. 이 작업은 되돌릴 수 없습니다. 확정 후 **미배정 사용자**가 남는지 확인하고 필요한 학생에게 수동 배정하세요.

### 신청 공지

공지 메시지를 입력해 자습 신청 화면에 표시합니다. 현재 공지의 삭제 버튼을 누르면 안내를 내립니다. 신청 시간이나 대상이 바뀌었다면 공지와 실제 설정이 일치하는지 확인하세요.

## 기숙사 신청 관리

달력에서 날짜를 선택하고 토요일 또는 일요일/공휴일 유형으로 활성화합니다. 학생은 활성화된 날짜에만 [](dorm.md)의 신청을 할 수 있습니다.

신청이 있는 날짜를 비활성화하면 그 날짜의 모든 기숙사 신청 데이터가 삭제됩니다. 경고창의 신청 건수를 확인한 뒤 실행하세요. 현재 학생 수정 마감은 적용일 전날 **18:00**입니다.
