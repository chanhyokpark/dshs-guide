# 학생·교사·관리자 설정

학생, 교사와 관리자의 설정 메뉴에는 프로필, 일반, 급식, 알림, 자습 신청, 외출 신청과 사이트 정보가 있습니다. 학부모 설정은 [](parent-settings.md)을 참고하세요.

## 프로필

프로필에는 학번, 이름, 동명이인 구분용 별칭, 이메일, 역할, 성별, 전화번호, 보호자 전화번호와 등록 연도가 표시됩니다. 프로필 사진은 이메일 기반 [Gravatar](https://gravatar.com)에서 변경합니다.

**정보 수정**에서는 노트, 교무실, 연락처처럼 다른 사용자의 사용자 선택 화면에도 활용될 수 있는 추가 정보를 편집합니다. 개인정보가 불필요하게 노출되지 않도록 필요한 내용만 입력하세요. 이 화면에서 로그아웃할 수도 있습니다.

## 일반

### 패스키

등록된 패스키 목록을 확인하고 새 패스키를 만들거나 삭제합니다. 사이트에서 삭제한 뒤 비밀번호 관리자에 남은 패스키는 직접 별도로 지워야 합니다. 자세한 로그인 방법은 [](login.md)을 참고하세요.

### 대체 이메일

학생·교사·관리자는 학교 메일 대신 인증 코드를 받을 주소를 등록·변경·삭제합니다. 대체 주소를 등록해도 로그인할 때 입력하는 ID는 기존 학교 계정입니다.

### Google 계정 연결

학교 Google 계정을 연결해 Drive 파일, Google Docs와 Classroom 기능을 사용합니다. 권한 요청에서 일부 항목을 빼면 관련 기능이 실패할 수 있습니다. 필요하지 않으면 **연동 해제**할 수 있습니다.

### 홍보 배너와 브라우저 설정

- 홍보 배너를 홈의 기본 위치 또는 아래쪽에 표시하도록 선택합니다.
- **모든 설정 초기화**를 두 번 눌러 이 브라우저에 저장된 급식, 자습, 외출 즐겨찾기와 화면 설정을 지웁니다.

계정 데이터나 서버에 저장된 신청·게시글은 브라우저 설정 초기화로 삭제되지 않습니다.

## 급식

알레르기 번호를 선택하면 일치하는 급식 메뉴가 빨간색으로 표시됩니다. 목록과 주의사항은 [](meal.md)을 참고하세요. 이 설정은 브라우저별입니다.

## 자습 신청

모든 항목은 현재 브라우저에 저장되며 아래 미리보기에서 바로 확인할 수 있습니다.

- **자습실 이미지 표시:** 구역 사진 표시
- **‘전체’ 탭 표시:** 실제 배치를 펼쳐 모든 좌석을 한 목록으로 표시
- **변형된 레이아웃 사용:** 실제 모양 일부를 단순화해 한 화면에 더 많은 좌석 표시
- **배지 표시:** 좌석에 학년 배지 표시
- **배지에 성별 표시:** 성별에 따라 배지 색 구분
- **사용자 지정 배지 색상:** 남·여 배지 색을 직접 선택
- **???:** 신청이 열리지 않은 상태의 빈 좌석에 임의 색상 효과 표시

## 외출 신청

특별실 신청의 장소 선택기에 표시할 즐겨찾기를 편집합니다. Enter로 항목을 추가하고 Backspace 또는 삭제 버튼으로 제거하며 위·아래 버튼으로 순서를 바꾼 뒤 저장합니다. 빈 이름은 저장할 수 없습니다.

## 사이트 정보

현재 웹 버전과 제작자 정보를 확인합니다. 업데이트 내역 메뉴에는 서비스가 공개한 버전별 변경 기록이 표시됩니다.
