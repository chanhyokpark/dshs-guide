# 역할별 기능

DSHS.APP은 계정 역할과 개별 권한에 따라 메뉴와 동작을 제한합니다. 아래 표는 일반적인 범위이며, 실제 화면에 표시되는 권한이 우선입니다.

| 기능 | 학생 | 교사 | 학부모 | 졸업생 | 관리자 |
|---|---|---|---|---|---|
| 자습·외출·상벌점 | 본인 신청·조회 | 조회·승인·운영 | 연결 학생 조회 | 사용 안 함 | 전체 운영 |
| 게시판 | 허용 게시판 사용 | 허용 게시판 사용·관리 | 허용 게시판 사용 | 허용 게시판 사용 | 전체 관리 |
| 메시지 | 교직원 등에게 전송 | 개인·단체 전송 | 허용 대상에게 전송 | 사용 안 함 | 개인·단체 전송 |
| 과제 | 조회·제출 | 생성·채점 | 사용 안 함 | 사용 안 함 | 생성·채점 |
| 온라인 저지 | 풀이·제출·기본 출제 | 풀이·제출·고급 출제 | 사용 안 함 | 기록 열람 | 전체 기능 |
| 사용자·신청 운영 | 사용 안 함 | 일부 담당 기능 | 사용 안 함 | 사용 안 함 | 전체 운영 |

## 학생 {id="student"}

학생끼리 새 1:1 대화를 시작할 수는 없습니다. 과제와 온라인 저지 제출, 학교생활 신청은 본인 계정으로 수행합니다.

## 교사

외출 승인, 상·벌점, 수업과 채점, 단체 메시지 등 담당 업무 메뉴를 사용합니다. 자습 신청 일정 변경이나 사용자 전체 관리처럼 관리자 권한이 필요한 작업은 할 수 없습니다.

## 학부모

연결된 학생의 자습·외출·상벌점 정보를 읽기 전용으로 확인합니다. 과제, 온라인 저지, 학교 Google 연동과 학생 대신 신청하는 기능은 제공하지 않습니다.

## 졸업생

허용된 게시판과 알림, Google 연동을 사용할 수 있습니다. 온라인 저지는 등록 후 기록을 읽을 수 있지만 새 제출이나 출제는 할 수 없습니다.

## 관리자

교사 기능과 함께 사용자, 자습·기숙사 일정, 운영 데이터 관리 기능을 사용합니다. 중요한 변경은 대상과 기간을 다시 확인한 뒤 실행하세요.

<note>
개발·시스템 계정은 운영 점검을 위해 별도 권한을 가질 수 있으므로 일반 사용자 안내의 대상이 아닙니다.
</note>
