# 로그인과 계정

DSHS.APP에서는 **로그인 계정(Account)**과 **서비스 사용자(User)**가 분리되어 있습니다.

- 계정은 로그인 이메일, 비밀번호, 패스키와 로그인된 기기를 보관합니다.
- 사용자는 이름·학번·역할·학교 정보와 게시글, 신청, 벌점, 알림 같은 서비스 기록을 보관합니다.
- 하나의 계정에 교사 사용자와 자녀별 학부모 사용자처럼 여러 사용자를 연결할 수 있습니다.
- 로그인한 뒤 현재 사용자를 바꾸어도 로그인 이메일과 패스키는 같은 계정 것을 사용하지만, 화면의 역할과 서비스 기록은 선택한 사용자 것으로 바뀝니다.

<warning>
로그인 화면에는 학교 계정 ID나 학부모 등록 주소가 아니라 <b>계정의 전체 로그인 이메일 주소</b>를 입력합니다.
학부모의 <code>parent-...@dshs.app</code> 주소는 사용자 등록에만 쓰며 로그인 주소가 아닙니다.
</warning>

## 일반 로그인

1. [로그인 페이지](https://dshs.app/login)를 엽니다. 별도 계정 서비스인 `auth.dshs.app`으로 이동할 수 있습니다.
2. **계정 이메일**에 등록된 전체 이메일 주소를 입력하고 **다음**을 누릅니다.
3. 비밀번호가 설정된 계정이면 비밀번호를 입력합니다.
4. 비밀번호가 없는 계정이면 로그인 이메일로 받은 **6자리 코드**를 입력합니다. 코드는 10분 뒤 만료됩니다.
5. 계정에 사용자가 여러 명이면 **사용할 사용자**를 선택합니다.

이메일 전송은 30초에 한 번만 요청할 수 있습니다. 메일이 최대 5분 늦게 도착할 수 있으므로 연속으로 재전송하지 말고 스팸함도 확인하세요.

로그인 뒤 다른 역할이나 자녀로 바꾸려면 화면 상단 계정 메뉴의 **사용자 전환**에서 원하는 사용자를 선택합니다. 사용자 전환은 로그아웃이 아니며 같은 로그인 세션 안에서 현재 User만 바꿉니다.

## 학생·교직원 계정 등록

처음 사용하는 학생·교직원은 미리 생성된 학교 사용자를 계정에 연결해야 합니다.

1. 로그인 화면에서 **계정 등록**을 누릅니다.
2. 학교 이메일 주소를 입력합니다. 등록 화면에서는 학교 계정 ID만 입력할 수도 있습니다.
3. 학교 이메일로 받은 6자리 코드를 입력합니다.
4. 화면의 이름·학번·역할이 본인 정보인지 확인합니다.
5. **새 계정 만들기**를 누릅니다.
6. 원하면 8자 이상의 비밀번호를 설정합니다. 비워 두면 이메일 코드 또는 패스키로 로그인합니다.
7. 등록이 끝나면 패스키를 추가하거나 **시작하기**를 누릅니다.

이미 다른 DSHS.APP 계정이 있다면 **기존 계정에 로그인해서 연결**을 선택할 수 있습니다. 이미 로그인한 상태에서는 **현재 계정에 연결**을 선택합니다.

## 학부모 등록: 먼저 준비할 정보 {id="parent-flow"}

학부모는 학교에서 자녀별로 다음 두 값을 받아야 합니다.

- `parent-...@dshs.app` 형식의 **학부모 등록 주소**
- 영문 대문자와 숫자로 된 **8자리 학부모 인증코드**

등록 주소는 자녀의 학부모 User를 찾는 식별자입니다. 학부모 본인의 이메일도, 등록 뒤 사용할 로그인 이메일도 아닙니다. 이전 방식처럼 자녀의 학번과 이름을 직접 입력하지 않습니다.

학생 한 명마다 별도의 학부모 User가 만들어집니다. 자녀가 여러 명이면 각 자녀의 등록 주소와 인증코드로 학부모 User를 하나씩 같은 계정에 추가한 뒤 **사용자 전환**으로 자녀를 바꿉니다.

## 학부모가 새 계정을 만드는 전체 순서

1. [계정 등록 페이지](https://auth.dshs.app/register)를 엽니다.
2. 학교에서 받은 `parent-...@dshs.app` 등록 주소를 입력하고 **다음**을 누릅니다.
3. **학부모 인증 코드** 입력 화면에 학교에서 받은 8자리 코드를 입력합니다.
4. 화면에 표시된 `학생이름 학부모` 사용자와 역할이 맞는지 확인합니다.
5. 개인정보 수집·이용과 이용약관을 각각 읽고 두 필수 항목에 동의합니다.
6. **새 계정 만들기**를 누릅니다.
7. 앞으로 로그인에 사용할 학부모 본인의 실제 이메일 주소를 입력합니다.
8. 원하면 8자 이상의 비밀번호를 설정합니다. 비워 두면 이메일 코드 또는 패스키로 로그인합니다.
9. **인증 코드 전송**을 누릅니다.
10. 7단계의 개인 이메일로 받은 **6자리 코드**를 입력합니다.
11. **계정 만들기**를 누릅니다. 계정이 생성되고 자녀의 학부모 User가 연결됩니다.
12. 원하면 패스키를 등록한 뒤 **시작하기**를 누릅니다.

<note>
학부모 등록에는 서로 다른 코드가 두 개 나옵니다. 학교가 준 <b>8자리 코드</b>는 자녀의 학부모 User를 증명하고, 개인 이메일로 받은 <b>6자리 코드</b>는 새 계정의 로그인 이메일을 증명합니다. 등록이 완료되면 8자리 코드는 폐기됩니다.
</note>

학부모 로그인 이메일에는 `gmail.com`, `naver.com`, `daum.net`, `icloud.com`, `outlook.com` 등 화면에서 허용하는 개인 이메일 도메인을 사용합니다. `parent-...@dshs.app` 등록 주소를 개인 이메일 칸에 다시 입력하면 안 됩니다.

## 기존 계정에 자녀 사용자 추가

이미 다른 자녀로 등록했거나 교사 계정이 있는 학부모는 새 로그인 계정을 만들지 않아도 됩니다.

### 이미 기존 계정으로 로그인한 경우

1. 상단 계정 메뉴에서 **계정 설정**을 열고 **연결된 사용자 | 다른 사용자 추가**를 누릅니다. 또는 [계정 등록 페이지](https://auth.dshs.app/register)를 직접 엽니다.
2. 추가할 자녀의 `parent-...@dshs.app` 등록 주소를 입력합니다.
3. 학교에서 받은 해당 자녀의 8자리 학부모 인증코드를 입력합니다.
4. 표시된 `학생이름 학부모` 사용자가 맞는지 확인하고 두 필수 동의 항목을 선택합니다.
5. **현재 계정(...)에 연결**을 누릅니다.
6. 완료 뒤 DSHS.APP 상단의 **사용자 전환**에서 새로 연결한 `학생이름 학부모`를 선택합니다.

이 과정에서는 기존 계정의 로그인 이메일을 그대로 사용하므로 개인 이메일 6자리 인증을 다시 하지 않습니다.

### 로그인하지 않은 경우

1. 등록 주소와 8자리 코드를 확인하고 필수 동의까지 진행합니다.
2. **기존 계정에 로그인해서 연결**을 누릅니다.
3. 기존 계정의 로그인 이메일과 비밀번호·이메일 코드·패스키 중 가능한 방법으로 로그인합니다.
4. 등록 화면으로 돌아오면 연결을 완료합니다.
5. 상단 **사용자 전환**에서 새 학부모 사용자를 선택합니다.

다른 계정에 연결하려는데 이미 원하지 않는 계정으로 로그인되어 있다면 먼저 로그아웃하세요. 한 학부모 User를 서로 다른 두 로그인 계정이 동시에 공유하는 기능은 현재 제공하지 않습니다.

## 패스키로 로그인

패스키는 Face ID, Touch ID, Windows Hello 또는 기기 잠금으로 로그인하는 방법입니다. 로그인 화면의 **패스키로 로그인**이나 브라우저 자동 완성 목록에서 계정을 선택합니다.

### 패스키 등록과 삭제

1. [계정 설정](https://auth.dshs.app/settings/account)을 엽니다.
2. **패스키 관리 | 패스키 생성**을 누르고 브라우저 또는 비밀번호 관리자의 안내를 따릅니다.
3. 필요 없는 패스키는 같은 목록에서 삭제합니다.

사이트에서 패스키를 삭제해도 기기의 비밀번호 관리자에 저장된 항목은 자동으로 지워지지 않습니다. 두 곳에서 각각 삭제해야 로그인 목록에 남지 않습니다.

## 계정 설정과 사용자 설정

[계정 설정](https://auth.dshs.app/settings/account)에서는 로그인 계정 전체에 공통인 항목을 관리합니다.

- 로그인 이메일 변경
- 비밀번호 설정·변경·삭제
- 패스키 생성·삭제
- 연결된 사용자 확인·연결 해제와 다른 사용자 추가

[로그인 기기](https://auth.dshs.app/settings/sessions)에서는 이 계정으로 로그인한 브라우저와 앱을 확인하고 개별 세션 또는 다른 모든 세션을 종료할 수 있습니다.

반면 DSHS.APP의 프로필, Google 계정 연결과 알림 설정은 **현재 선택한 사용자**에 적용됩니다. 설정하기 전에 상단의 현재 사용자 이름을 확인하세요. 마지막 연결 사용자를 계정에서 해제하면 로그인 계정과 비밀번호·패스키·세션이 삭제되지만 학교 User와 기존 서비스 기록이 곧바로 삭제되는 것은 아닙니다.

## Google 계정 연결

Google 계정 연결은 로그인 방법이 아니라 현재 User가 Google Drive 첨부와 Classroom 가져오기를 사용할 수 있게 하는 별도 권한입니다.

1. DSHS.APP에서 <ui-path>설정 | 일반 | Google 계정</ui-path>을 엽니다.
2. 학교 Google 계정을 선택합니다.
3. 요청되는 권한을 모두 허용합니다. 일부만 허용하면 Drive 또는 Classroom 기능이 동작하지 않을 수 있습니다.

같은 로그인 계정의 다른 User로 전환하면 Google 연결도 그 User의 별도 설정으로 바뀝니다.

## 로그인 문제 해결 {id="troubleshooting"}

- **등록 주소로 로그인할 수 없음:** `parent-...@dshs.app`은 등록 전용입니다. 등록 때 인증한 학부모 본인의 계정 이메일을 입력하세요.
- **학교 계정 ID로 로그인할 수 없음:** 로그인 화면에는 `@djshs.djsch.kr`까지 포함한 현재 계정 이메일 전체를 입력하세요. 등록 뒤 이메일을 변경했다면 변경한 주소를 사용합니다.
- **다른 자녀 정보가 보임:** 상단 **사용자 전환**에서 현재 `학생이름 학부모` 사용자를 확인하세요.
- **자녀를 추가할 수 없음:** 새 자녀의 등록 주소와 8자리 코드가 각각 필요합니다. 이미 다른 계정에 연결된 사용자라면 학교 관리자에게 연결 해제와 코드 재발급을 요청하세요.
- **메일이 오지 않음:** 입력한 계정 이메일을 확인하고 최대 5분 기다린 뒤 스팸함을 확인합니다.
- **패스키가 보이지 않음:** 패스키를 저장한 비밀번호 관리자와 동기화 계정을 확인합니다. 다른 방법으로 로그인한 뒤 새 패스키를 추가할 수도 있습니다.
- **앱 안 브라우저가 열림:** 카카오톡 등의 메뉴에서 **기본 브라우저로 열기**를 선택합니다.
- **삼성 인터넷:** 지원되지 않으므로 Android 앱 또는 Chrome으로 바꿉니다.
- **학교 메일이나 기존 학부모 이메일에 접근할 수 없음:** 이미 로그인된 기기가 있으면 계정 설정에서 로그인 이메일을 변경하고, 그렇지 않으면 [](contact.md)으로 문의합니다.

학부모 등록만 자세히 다시 보려면 [](parent-registration.md), 등록 뒤 사용자 전환과 설정은 [](parent-settings.md)을 참고하세요.
