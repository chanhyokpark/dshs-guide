# 로그인 및 계정 설정

로그인 화면에서 계정에 등록된 방법을 선택합니다. 계정 상태에 따라 패스키, 이메일 인증 코드 또는 비밀번호 입력란이 표시됩니다.

## 패스키로 로그인

1. **패스키로 로그인**을 선택합니다.
2. 기기의 생체 인증, 화면 잠금 또는 보안 키로 본인임을 확인합니다.
3. 로그인 완료 후 홈으로 이동하는지 확인합니다.

패스키가 없는 기기에서는 이메일 로그인으로 들어간 뒤 새 패스키를 등록할 수 있습니다.

## 이메일로 로그인

1. 학교 또는 계정 이메일을 입력합니다.
2. **인증 코드 보내기**를 선택합니다.
3. 받은 편지함의 코드를 입력합니다.
4. 비밀번호가 설정된 계정은 화면이 전환되면 비밀번호를 입력합니다.

메일이 오지 않으면 주소의 오타, 스팸함, 이전에 요청한 코드가 아닌 최신 코드인지 확인하세요.

## 학부모 계정 등록

학부모는 로그인 화면의 학부모 등록 절차를 사용합니다.

1. 학생의 학번과 이름을 입력합니다.
2. 학교에서 안내받은 학부모 접근 코드를 입력합니다.
3. 학부모 이메일을 인증합니다.
4. 필요하면 패스키를 등록합니다.

연결 학생을 추가하거나 관리하는 방법은 [](parent.md)을 참고하세요.

## 첫 로그인 뒤 확인할 항목

- 교사 계정은 학교 Google 계정 연결이 먼저 요구될 수 있습니다.
- 패스키 등록 안내가 나타나면 현재 기기에 등록하거나, 다른 로그인 수단이 있을 때 나중에 설정합니다.
- 알림과 브라우저 권한을 확인합니다.

<warning>
인증 코드, 비밀번호, 학부모 접근 코드를 다른 사람에게 전달하지 마세요. 접근 코드를 잃어버렸다면 학교 담당자에게 새 코드 발급을 문의하세요.
</warning>
