# 기숙사 신청

기숙사 신청에서는 주말·공휴일에 기숙사에서 자습할 시간대를 정합니다. 현재 수정 마감은 **적용일 전날 오후 6시**입니다.

## 시간대

각 날짜에 다음 다섯 항목을 선택할 수 있습니다.

- 오전
- 오후
- 1자
- 2자
- 3자

체크한 시간에는 기숙사를 사용하겠다는 뜻입니다. 특별실이나 외출 신청과 시간이 겹치면 승인된 실제 일정에 맞게 정리하세요.

## 기본값과 날짜별 신청

1. 기숙사 신청 화면에서 **토요일 기본값**과 **일요일/공휴일 기본값**을 먼저 설정합니다.
2. 달력에서 실제 신청 가능한 날짜를 선택합니다.
3. 기본값과 다르게 사용할 시간대를 체크하거나 해제합니다.
4. **저장**을 누릅니다.

날짜별 값을 따로 저장하지 않으면 해당 요일의 기본값이 사용됩니다. 기본값을 바꾸더라도 이미 날짜별로 따로 저장한 신청에는 자동으로 덮어쓰지 않을 수 있으므로 각 날짜를 확인하세요.

전날 오후 6시가 지나면 해당 날짜의 모든 시간대가 읽기 전용이 됩니다. 현재 서비스 화면에는 과거 문서에 있던 ‘당일 야간만 수정’ 기능이 활성화되어 있지 않습니다.

## 신청 가능한 날짜가 없을 때

관리자가 신청 날짜를 열어야 달력에 나타납니다. 학교 일정상 기숙사 신청이 필요하지 않은 날에는 아무 날짜도 표시되지 않을 수 있습니다. 관리자 운영 방법은 [](admin-operations.md)을 참고하세요.
