# 교사 홈과 빠른 검색

교사 홈은 학생 상태 검색, 업무 바로가기, 날짜별 자료, 담당 수업과 급식을 한 화면에 모읍니다.

## 빠른 검색

검색창에 학생 학번·이름, 독서실 구역 또는 좌석명을 입력하고 Enter를 누릅니다. 결과에서 학생을 선택하면 다음 정보를 확인할 수 있습니다.

- 받은 벌점·상점과 유효 점수, 도달한 기준점
- 오늘 자습 좌석과 해당 좌석 화면으로 이동
- 현재 진행 중인 외출·특별실 신청
- 아직 승인되지 않은 신청
- 해당 학생을 미리 선택한 상·벌점 부여 화면

좌석이나 구역을 검색하면 자습 현황의 해당 위치로 이동합니다. 전체 학생을 조건별로 찾으려면 [](query-students.md)을 사용하세요.

## 바로가기

교사 홈에서 외출 신청, 학생 목록, 벌점 부여, 벌점 기록, 자습 현황과 이 가이드를 바로 열 수 있습니다.

## 운영 자료와 수업

- 오늘 자습, 외출과 상·벌점 자료를 내려받습니다.
- 신청 가능한 경우 오늘·내일의 기숙사 자료를 내려받습니다.
- 담당 수업의 최근 현황을 확인하거나 새 수업을 만듭니다.
- 오늘의 급식을 확인하고 전체 급식 화면으로 이동합니다.

자료 형식과 주의사항은 [](export.md), 수업 화면은 [](courses.md)을 참고하세요.
