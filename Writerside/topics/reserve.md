# 자습 좌석 신청

자습 신청에서는 독서실 또는 세미나실 좌석을 선착순으로 신청하고 실시간 현황을 확인합니다. 현재 기본 신청 시간은 **오후 9시부터 오후 11시까지**, 한 기간의 최대 신청·변경 횟수는 **10회**입니다. 실제 날짜별 시간이 관리 화면에서 변경되면 해당 신청 화면에 표시된 시간이 우선합니다.

## 날짜 선택 화면

자습 신청 첫 화면에는 오늘 좌석, 다음 신청 가능 날짜와 시작 시각이 표시됩니다.

- **오늘 보기:** 현재 사용 중인 기간의 좌석과 전체 현황 확인
- **다음 자습 신청:** 다음 기간에 사용할 좌석 신청
- **과거 날짜:** 날짜를 골라 종료된 신청 현황 확인
- **연습 모드:** 실제 좌석에 영향을 주지 않는 10초 또는 30초 타이머 연습

<warning>
다음 기간 좌석을 신청할 때 <b>오늘 보기</b>가 아니라 <b>다음 자습 신청</b>을 여는지 먼저 확인하세요.
</warning>

## 좌석 신청하기

1. 신청할 날짜를 열고 상단의 날짜와 상태를 확인합니다.
2. 햇빛마루, 달빛마루, 별빛마루 또는 설정에서 활성화한 **전체** 탭을 선택합니다.
3. 필요하면 구역을 선택하거나 학생·학번·좌석명으로 검색합니다.
4. 연결 상태가 정상이고 신청이 시작되면 비어 있는 좌석을 한 번 누릅니다.
5. 처리 창이 닫힌 뒤 내 이름과 좌석이 표시되는지 확인합니다.

신청을 한 번 시도하면 성공 여부와 관계없이 다음 시도까지 최소 **5초** 기다려야 합니다. 시작 전에 좌석을 누르면 해당 기기에서 **5초간** 신청이 제한됩니다. 버튼을 반복해서 누르거나 여러 기기에서 동시에 시도하지 마세요.

## 변경·취소·자리 교환

### 빈 좌석으로 변경

신청 시간 안에 다른 빈 좌석을 누르면 현재 좌석에서 새 좌석으로 이동합니다. 화면의 정보 메뉴에서 **총 변경 횟수 10회**와 남은 횟수를 확인할 수 있습니다.

### 신청 취소

내 좌석을 마우스 오른쪽 버튼으로 누르거나 모바일에서 길게 눌러 **신청 취소**를 선택합니다. 남은 변경 횟수가 없으면 취소할 수 없습니다. 취소 후 다시 신청하면 추가 횟수가 사용될 수 있으므로 단순 이동은 새 좌석을 바로 선택하세요.

### 다른 학생과 교환

1. 서로 좌석을 신청한 상태에서 상대 좌석을 오른쪽 클릭하거나 길게 누릅니다.
2. **자리 바꾸기 요청**을 보냅니다.
3. 상대가 요청을 수락하면 두 좌석이 한 번에 교환됩니다.

요청을 처리하는 동안 두 학생 모두 좌석을 바꾸거나 취소하지 않아야 하고 변경 가능 횟수가 남아 있어야 합니다. 수락되어 실제 교환된 경우 알림이 오며, 거절되거나 조건이 맞지 않아 실패한 경우에는 알림이 오지 않을 수 있습니다.

## 화면 도구

- **잠금:** 실수로 좌석을 누르지 않도록 신청 버튼을 잠급니다.
- **검색:** 이름, 학번, `a1` 같은 구역, `a101` 같은 좌석을 찾습니다.
- **신청 정보:** 신청자 수, 전체·남은 변경 횟수, 날짜와 상태를 확인합니다.
- **연결 상태:** 연결 중, 데이터 가져오는 중 또는 오프라인이면 신청할 수 없습니다. 오래 지속되면 새로고침합니다.
- **신청 기록:** 수신한 실시간 변경, 내 신청 결과와 오류를 확인합니다. 문제가 발생하면 기록 전송 기능으로 진단 자료를 보낼 수 있습니다.
- **시간 보정:** 기기와 서버 시간의 차이가 감지되면 타이머를 눌러 보정합니다. 외부 서버 시간 사이트보다 화면에 표시된 보정값을 사용하세요.
- **공지:** 운영자가 보낸 신청 공지를 확인하고 읽은 공지는 닫을 수 있습니다.

## 연습 모드

연습 모드는 실제 신청과 분리되어 있습니다. 10초 또는 30초 연습을 시작한 뒤 타이머가 0이 되는 순간 좌석을 눌러 봅니다. 결과에는 사용자가 누른 시점과 서버가 받은 시점의 차이가 표시되므로 기기·네트워크 상태를 점검할 수 있습니다.

연습 모드는 iOS에서 지원하지 않습니다.

## 학부모·교사 화면

- 학부모는 선택한 자녀의 좌석과 전체 현황을 읽기 전용으로 확인합니다. 신청, 변경, 취소와 자리 교환은 할 수 없습니다.
- 교사와 관리자는 현황을 조회하고 학생 검색 결과에서 해당 좌석으로 바로 이동할 수 있습니다.
- 관리자는 [](admin-operations.md)에서 날짜, 시간, 참여자와 좌석을 운영합니다.
