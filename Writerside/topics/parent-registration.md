# 학부모 계정 등록

학부모 계정은 학생의 **학번, 이름, 학부모 인증 코드**와 학부모가 사용할 이메일로 만듭니다. 인증 코드는 학교에서 안내받아야 하며, 계정 등록 후에도 다른 자녀를 연결할 때 다시 필요합니다.

## 등록 순서

1. [로그인 화면](https://dshs.app/login) 아래의 **학부모 등록**을 선택합니다.
2. 자녀의 4자리 학번, 이름과 학부모 인증 코드를 입력합니다.
3. 자녀가 여러 명이면 **학생 추가**로 같은 단계에서 모두 입력합니다.
4. 로그인에 사용할 학부모 이메일을 입력하고 인증 코드 전송을 누릅니다.
5. 이메일로 받은 **6자리 코드**를 입력합니다. 코드는 **10분 뒤 만료**됩니다.
6. 계정 생성 완료 후 바로 로그인하고, 원하면 패스키를 등록합니다.

메일 도착에는 최대 5분이 걸릴 수 있습니다. 입력한 이메일과 스팸함을 확인하고 연속으로 재전송하지 마세요.

## 기존 학부모 계정 경고

입력한 학생에게 이미 다른 학부모 계정이 연결되어 있으면 대상 학생 목록과 함께 경고가 표시됩니다. **기존 계정을 삭제하고 계속**을 선택하면 기존 학부모 계정이 삭제되어 더 이상 로그인할 수 없습니다.

## 등록 후 로그인

다음부터는 등록한 이메일로 인증 코드를 받거나 패스키를 사용합니다. 학부모의 로그인 이메일은 <ui-path>설정 | 일반</ui-path>에서 새 이메일 인증을 거쳐 변경할 수 있습니다.

학번·이름·코드가 맞는데도 등록되지 않으면 코드의 앞뒤 공백과 학번을 확인한 뒤 [](contact.md)으로 문의하세요.
