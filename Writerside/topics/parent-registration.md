# 학부모 계정 등록

학부모 등록은 보호자의 로그인 계정을 새로 만들거나, 자녀별로 미리 생성된 **학부모 사용자**를 기존 계정에 연결하는 과정입니다. 전체 화면 순서는 [](login.md#parent-flow)에서 자세히 설명합니다.

## 준비할 정보

학교에서 자녀별로 다음 두 값을 받습니다.

- `parent-...@dshs.app` 형식의 학부모 등록 주소
- 영문 대문자와 숫자로 된 8자리 학부모 인증코드

등록 주소는 로그인 이메일이 아닙니다.

## 새 로그인 계정 만들기

1. [계정 등록](https://auth.dshs.app/register)을 엽니다.
2. 학부모 등록 주소를 입력합니다.
3. 학교가 준 8자리 인증코드를 입력합니다.
4. 표시된 `학생이름 학부모` 사용자를 확인하고 개인정보 수집·이용과 이용약관에 동의합니다.
5. **새 계정 만들기**를 선택합니다.
6. 실제로 사용할 개인 로그인 이메일과 선택 비밀번호를 입력합니다.
7. 개인 이메일로 받은 6자리 코드를 입력해 계정을 만듭니다.
8. 원하면 패스키를 등록합니다.

학교가 준 8자리 코드는 자녀의 학부모 사용자용이고, 이메일로 받은 6자리 코드는 새 계정 이메일용입니다. 등록이 끝나면 8자리 코드는 다시 사용할 수 없습니다.

## 기존 계정에 연결하기

이미 다른 자녀의 학부모 사용자나 교사 사용자가 연결된 계정이 있다면 그 계정을 그대로 사용합니다.

1. 기존 계정으로 로그인합니다.
2. [계정 설정](https://auth.dshs.app/settings/account)의 **다른 사용자 추가**를 누릅니다.
3. 새 자녀의 등록 주소와 8자리 코드를 입력하고 필수 동의를 확인합니다.
4. **현재 계정에 연결**을 누릅니다.
5. DSHS.APP 상단 **사용자 전환**에서 새 `학생이름 학부모` 사용자를 선택합니다.

로그아웃 상태라면 등록 과정에서 **기존 계정에 로그인해서 연결**을 선택할 수 있습니다. 자녀마다 별도의 등록 주소와 코드가 필요합니다.

## 기존 연결과 접근 권한

새 등록이 예전 학부모 계정 전체나 다른 자녀 연결을 자동 삭제하지 않습니다. 등록하려는 학부모 사용자가 이미 다른 계정에 연결되어 있거나 기존 이메일에 접근할 수 없다면 학교 관리자에게 다음 순서의 처리를 요청하세요.

1. 해당 학부모 사용자와 기존 로그인 계정의 연결 해제
2. 새 8자리 인증코드 발급
3. 같은 등록 주소와 새 코드로 다시 등록
