# 그룹·게시판 관리

권한이 있는 사용자는 그룹과 게시판을 만들고 멤버와 공개 범위를 관리할 수 있습니다.

## 그룹과 게시판 만들기

1. 게시판 관리 화면에서 **새 그룹** 또는 **새 게시판**을 선택합니다.
2. 이름, 설명과 표시 방식을 입력합니다.
3. 공개 여부, 비밀글, 허용 역할을 설정합니다.
4. 필요한 하위 게시판을 만들고 저장합니다.

그룹에 연결된 게시판은 그룹 멤버를 기준으로 접근 권한을 관리할 수 있습니다. 초대 코드를 발급한 경우 의도한 대상에게만 전달하세요.

## 멤버 관리

- 멤버 추가·제거
- 관리자 권한 부여·회수
- 그룹과 연결된 게시판 접근 확인
- 하위 게시판과 공개 범위 점검

<warning>
공개 범위나 허용 역할을 바꾸면 기존 글의 노출 범위도 달라질 수 있습니다. 저장하기 전에 비공개 자료가 있는지 확인하세요.
</warning>
