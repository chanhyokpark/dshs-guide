# 전체 게시판·그룹 관리

관리자는 일반 게시판 관리자와 별도로 서비스의 게시판·그룹을 전체 검색하고 기본 설정, 소유권과 삭제를 관리할 수 있습니다. 현재 사이드바에는 링크가 숨겨져 있으며 다음 주소로 직접 엽니다.

- 게시판 관리: [dshs.app/admin/boards](https://dshs.app/admin/boards)
- 그룹 관리: [dshs.app/admin/groups](https://dshs.app/admin/groups)

## 게시판 관리

게시판 이름 또는 UID를 검색하고 `*`로 전체 목록을 불러옵니다. 이름, 멤버 수, 게시글 수 등의 화면 제공 기준으로 정렬하고 페이지를 이동합니다.

각 게시판에서 다음 작업을 할 수 있습니다.

- 이름·설명 수정
- 공개 게시판 여부 변경
- 새 소유자의 사용자 UUID를 입력해 소유권 이전
- 게시판과 모든 게시글을 영구 삭제

세부 댓글·글쓰기·초대 권한과 멤버는 일반 게시판 설정에서 관리합니다. [](board.md)을 참고하세요.

## 그룹 관리

그룹 이름 또는 UID를 검색하고 `*`로 전체 목록을 불러옵니다. 이름, 멤버 수 또는 유형 기준으로 정렬합니다. 목록에는 유형, 소유자, 멤버·게시판 수와 공개 여부가 표시됩니다.

각 그룹에서 다음 작업을 할 수 있습니다.

- 이름·설명 수정
- 공개 그룹 여부 변경
- 새 소유자의 사용자 UUID를 입력해 소유권 이전
- 그룹 삭제

변경 불가 시스템 그룹은 삭제할 수 없습니다. 일반 그룹을 삭제해도 그 그룹에 연결되었던 게시판은 삭제되지 않습니다.

<warning>
소유권 이전 입력란은 학번이 아니라 내부 사용자 UUID를 요구합니다. 대상 계정을 정확히 확인하세요. 게시판 삭제는 모든 글과 댓글까지 영구 삭제되며 되돌릴 수 없습니다.
</warning>
