# 시작하기

DSHS.APP의 주요 기능은 웹에서 사용할 수 있으며, iOS와 Android에서는 전용 앱도 제공합니다. 학생과 교사는 스마트폰 한 대 이상에서 앱 알림을 사용할 수 있도록 등록하는 것이 권장됩니다.

## 기기별 선택

| 기기 | 권장 방법 | 참고 |
|---|---|---|
| iPhone·iPad | iOS 앱 | [](start_app.md) |
| Android | Android 앱 | [](android_app.md) |
| Windows·Linux | Chrome 또는 Firefox 웹 | [](start_web.md) |
| macOS | Safari, Chrome 또는 Firefox 웹 | macOS 앱 지원 종료 |

<warning>
macOS 네이티브 앱은 더 이상 지원하지 않습니다. 기존 앱을 사용하지 말고 [웹사이트](https://dshs.app)에 접속하세요. iOS와 Android 앱의 지원은 계속됩니다.
</warning>

## 처음 사용하는 순서

1. 기기에 맞는 웹 또는 앱을 엽니다.
2. [](login.md)에 따라 로그인합니다. 학부모는 [](parent-registration.md)에서 먼저 계정을 등록합니다.
3. 알림 권한을 허용하고 [](notifications.md)에서 받을 항목을 확인합니다.
4. 역할별 가이드로 이동합니다.
   - [](student.md)
   - [](teacher.md)
   - [](parent.md)

## 지원되지 않는 환경

- 삼성 인터넷 브라우저는 지원되지 않습니다. Android 앱 또는 Chrome을 사용하세요.
- 카카오톡 등 앱 안에서 열리는 내장 브라우저에서는 로그인이 정상적으로 진행되지 않을 수 있습니다. 외부 브라우저로 여세요.
- 오래된 Android 앱은 업데이트 전까지 이용이 제한될 수 있습니다.
