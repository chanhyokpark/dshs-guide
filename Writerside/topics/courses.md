# 수업·분반과 Classroom 가져오기

<warning>
이 설명은 최신 정보가 아닙니다. AI 도움말을 참조하세요.
</warning>

교사와 관리자는 하나의 수업 아래 여러 분반을 만들고 같은 글·과제를 여러 분반에 동시에 배포합니다. 관리자는 **전체 수업 보기**로 다른 교사의 수업도 확인할 수 있습니다.

## 수업 만들기

1. **수업**에서 **새 수업**을 누릅니다.
2. 수업 이름, 선택 사항인 과목과 학기를 입력합니다.
3. 수업 설정에서 담당 교사를 추가합니다. 담당 교사는 최소 한 명 있어야 합니다.
4. **분반 추가**에서 이름을 정하고 사용자 선택 또는 붙여 넣은 학번으로 학생을 추가합니다. 학번은 공백·줄바꿈·쉼표로 구분할 수 있습니다.
5. 각 분반의 학생 명단과 게시판 설정을 확인합니다.

새로 추가한 학생은 해당 분반에 이미 배포된 과제에도 자동으로 대상 지정될 수 있으므로 과제 현황을 확인하세요.

## 분반 게시판 템플릿

수업 설정에서 앞으로 만들 분반의 기본 게시판을 정합니다.

- 목록형 또는 Padlet형 보기
- 댓글 허용
- 학생 글쓰기 허용
- 첨부파일 허용
- 카테고리와 기본 카테고리

**기존 분반에도 적용**을 켜면 이미 운영 중인 분반 설정도 함께 바뀝니다. 저장 전에 각 분반의 특별 설정이 덮어써져도 되는지 확인하세요.

## 여러 분반에 글 쓰기

1. 수업 대시보드에서 **글 작성**을 누릅니다.
2. 게시할 분반을 하나 이상 선택합니다.
3. 글 유형, 제목, 본문과 첨부를 작성합니다.
4. 과제라면 분반별 마감 시각을 다르게 지정할 수 있습니다.
5. 바로 게시하거나 예약 게시 시각을 정합니다.

수업 대시보드의 게시글 영역에서 분반별로 만들어진 글을 함께 확인할 수 있습니다.

## 과제 현황

대시보드는 과제별 제출, 미제출, 채점 완료, 기한 초과와 예약 상태를 요약합니다. 미제출 학생에게 **쪽지 보내기**를 사용하면 각 학생의 1:1 대화로 안내가 전달됩니다. 수업 전체 성적 자료도 내보낼 수 있습니다.

세부 채점은 [](assignment-management.md)을 참고하세요.

## Google Classroom 가져오기

1. [](login.md)에 따라 학교 Google 계정을 연결하고 요청 권한을 모두 허용합니다.
2. 수업 목록에서 **Google Classroom에서 가져오기**를 엽니다.
3. 가져올 Classroom 수업을 선택합니다.
4. 진행 단계와 완료 보고서를 확인합니다.

수업, 학생 명단, 과제, 공지와 자료를 가져옵니다. **제출물과 성적은 가져오지 않습니다.** 같은 수업을 다시 가져오면 새 항목만 추가하며, 중간에 실패한 뒤 재시도해도 이미 가져온 항목은 건너뜁니다.

DSHS.APP에 학교 Google 계정을 연결한 학생만 자동으로 일치합니다. 완료 보고서의 **매칭되지 않은 학생**은 분반 설정에서 학번으로 직접 추가하세요.

## 수업 정리

- 기본 정보와 학기 수정
- 담당 교사 추가·제거
- 수업 보관 또는 보관 해제
- 담당 교사 구성을 유지한 채 새 수업으로 복사하고 분반은 새로 구성
- 분반 명단·게시판 설정 관리
- 수업과 연결 분반·게시글·제출을 포함한 삭제

삭제는 영향 범위가 크므로 경고창에 표시된 수업 이름과 삭제 대상을 확인하세요.
