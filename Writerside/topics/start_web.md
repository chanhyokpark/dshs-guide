# 웹에서 시작하기

웹사이트 주소는 [https://dshs.app](https://dshs.app)입니다. 주소가 비슷한 다른 사이트에 학교 계정 정보를 입력하지 마세요.

## 권장 브라우저

- 데스크톱: 최신 Chrome, Firefox 또는 Safari
- Android: 최신 Chrome
- iPhone·iPad: 웹보다 [](start_app.md)의 iOS 앱 권장
- macOS: 최신 Safari, Chrome 또는 Firefox

삼성 인터넷은 지원되지 않습니다. 화면 폭이 매우 좁은 기기에서는 일부 표와 좌석 배치가 가로로 스크롤될 수 있습니다.

## 홈 화면에 설치하기

브라우저가 PWA 설치를 지원하면 DSHS.APP을 별도 창으로 설치할 수 있습니다.

1. Chrome에서 [dshs.app](https://dshs.app)을 엽니다.
2. 브라우저 메뉴에서 **앱 설치** 또는 **홈 화면에 추가**를 선택합니다.
3. 생성된 아이콘으로 실행합니다.

PWA를 설치해도 iOS·Android 전용 앱과 동일해지는 것은 아닙니다. 푸시 알림이 중요하면 전용 앱을 사용하세요.

## 여러 기기와 브라우저

계정 정보, 게시글, 신청과 메시지는 서버에 저장됩니다. 다만 급식 알레르기, 자습 화면 표시 방식, 특별실 즐겨찾기와 광고 위치 같은 일부 설정은 현재 브라우저에만 저장됩니다. 브라우저 데이터를 지우거나 다른 기기로 옮기면 다시 설정해야 합니다.

자습 신청 중에는 여러 기기를 동시에 조작하지 마세요. 신청 직전에는 사용할 기기 하나를 정하고 네트워크 상태를 확인하는 것이 안전합니다.
