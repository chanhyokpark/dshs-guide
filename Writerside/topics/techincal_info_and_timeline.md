# 기술 정보 및 연혁

## 기술 정보
### 구버전 웹사이트 (2024-2024)
+ 프레임워크: Next.JS
+ 사용 언어: TypeScript
+ DB: MongoDB + Mongoose, Redis
+ 프론트엔드 라이브러리: React 18, Tailwind CSS
+ 호스팅: Vercel

### 신버전 웹사이트 (2025-)
+ 프레임워크: SvelteKit
+ 사용 언어: TypeScript
+ 프론트엔드 라이브러리: Svelte 5, shadcn-svelte, Tailwind CSS

### 신버전 API 및 마이크로서비스 (2026-)
+ 프레임워크: NestJS, Axum
+ 사용 언어: TypeScript, Rust
+ DB: PostgreSQL + Prisma ORM, Redis
+ DevOps: GitHub Actions, Kubernetes
+ 호스팅: AWS LightSail
+ 사용 서비스: Google Cloud API, AWS SES, AWS S3

### iOS 앱
+ 프레임워크: SwiftUI
+ 사용 언어: Swift

### 안드로이드 앱
+ 사용 언어: Kotlin

### 이 문서
+ JetBrains Writerside

## 연혁
+ 2024년 3월: 웹사이트가 처음 개발되었습니다. 첫 출시 때는 자습 신청, 상/벌점 부여 및 확인, 외출/기숙사 신청 기능을 가지고 있었습니다.
+ 2024년 4월: 독서실 자리 신청 기능에 WebSocket을 이용한 실시간 업데이트 기능을 추가했습니다.
+ 2024년 5월: 외출 신청 기능을 참여자를 추가할 수 있는 등의 기능을 추가해 다시 개발했습니다.
+ 2024년 7월: 공식 API를 구현하고 이를 이용한 iOS 앱을 출시했습니다.
+ 2024년 8월: 벌점 내역 페이지를 추가하고 벌점을 취소할 수 있게 개선했습니다.
+ 2025년 3월: 당시 막 출시된 Svelte 5를 이용해 웹사이트를 처음부터 다시 작성했습니다. 사용자 인터페이스가 매우 향상되었습니다. 패스키 기반 로그인을 기본값으로 사용해 보안 수준을 높였습니다.
+ 2025년 5월: 독서실 자리 신청 기능에 취소 기능을 추가했습니다.
+ 2025년 6월: Android 앱을 출시했습니다.
+ 2026년 3월: 사이트의 대부분을 새로 작성했습니다. 호스팅 서비스를 AWS LightSail로 변경하고 Kubernetes를 도입했습니다. DB를 PostgreSQL로 변경했습니다. 게시판/그룹/과제 시스템과 관리자 시스템을 추가했습니다. '레디스쿨'이라는 이름으로 개인사업자 등록을 받았습니다.
+ 2026년 5월: 온라인 저지 서비스의 초기 버전을 작성했습니다.
+ 2026년 8월: 폼, 메시지, 학부모 계정, 온라인 저지와 같은 수많은 기능을 추가했고 많은 개선사항을 적용했습니다. 사이트의 백엔드를 NestJS 기반으로 분리했습니다.
