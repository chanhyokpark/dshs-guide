# 사용자 관리와 명단 동기화

**관리자 > 사용자 관리**에서 계정을 검색·정렬하고 새 사용자를 만들거나 여러 계정을 일괄 처리합니다.

## 검색과 목록

검색창에는 학번·이름을 입력하고 `*`로 전체 사용자를 불러옵니다. 학번, 이름, 역할, 벌점 또는 학년 기준과 오름·내림차순을 조합해 정렬합니다. 목록은 20명씩 페이지로 나뉩니다.

각 행에는 학번·이름·이메일, 역할과 벌점이 표시됩니다. 시스템 계정은 선택·편집 대상에서 제외됩니다.

## 사용자 추가

**사용자 추가**에서 다음 정보를 입력합니다.

- 필수: 이름, 학번, 이메일, 역할
- 선택: 성별, 전화번호, 학부모 전화번호

이메일과 학번이 다른 계정과 중복되지 않는지, 역할이 학생·교사·관리자·학부모 중 실제 대상과 맞는지 확인하세요.

## 사용자 수정

사용자 행 또는 편집 버튼을 눌러 이름, 별명, 이메일, 학번, 역할, 성별, 전화번호와 학생의 학부모 전화번호를 바꿉니다. 역할 변경은 사이드바와 모든 기능 권한에 영향을 주므로 특히 주의하세요.

## 일괄 작업

체크 상자로 현재 페이지의 여러 사용자를 선택합니다.

- **삭제:** 계정을 비활성화합니다. 화면 경고에는 되돌릴 수 있는 작업으로 안내되지만 이 페이지에는 별도의 복구 버튼이 없으므로 복구 절차를 확인한 뒤 실행하세요.
- **벌점 초기화:** 선택한 모든 사용자의 벌점을 0으로 초기화합니다.
- **CSV 내보내기:** 현재 불러온 사용자의 학번, 이름, 이메일, 역할, 학년·반·번호와 벌점을 UTF-8 CSV로 저장합니다.

전체 선택은 현재 화면에 표시된 시스템 계정 이외의 사용자에게 적용됩니다. 페이지와 검색 조건을 먼저 확인하세요.

## Google 스프레드시트 동기화

관리자 자신의 학교 Google 계정을 [](login.md)에 따라 연결해야 합니다.

### 내보내기

1. **스프레드시트 > 내보내기**를 선택합니다.
2. 새 Google 스프레드시트를 생성합니다.
3. 생성된 링크를 복사하거나 바로 엽니다.
4. 필요한 값을 지정된 열에서 수정합니다.

### 가져오기

1. 스프레드시트 URL 또는 ID를 입력합니다.
2. 가져오기를 실행합니다.
3. 결과 창에서 생성, 수정, 비활성화, 변경 없음과 오류 항목을 확인합니다.
4. 표본 사용자를 사용자 목록에서 다시 엽니다.

가져오기 결과가 잘못되었다면 같은 결과 창의 **동기화 되돌리기**로 해당 동기화 이력의 변경을 롤백할 수 있습니다. 되돌리기 결과에는 복원된 계정과 제거된 새 계정 수가 표시됩니다.
