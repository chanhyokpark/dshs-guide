# 온라인 저지 출제

학생은 허용된 범위에서 기본 문제를 만들 수 있고, 교사와 관리자는 테스트 데이터 등 고급 출제 기능을 사용할 수 있습니다.

## 기본 문제 만들기

1. 온라인 저지의 문제 관리에서 **새 문제**를 선택합니다.
2. 제목, 설명, 입력·출력 형식과 예제를 작성합니다.
3. 시간·메모리 제한과 허용 언어를 설정합니다.
4. 테스트 데이터를 확인하고 저장합니다.
5. 공개 전에 직접 풀이를 제출해 채점을 검증합니다.

## 고급 출제

교사·관리자는 추가 테스트 자산과 세부 채점 설정을 사용할 수 있습니다. 큰 테스트 파일을 올리기 전에 형식과 제한을 확인하세요.

<warning>
잘못된 정답 데이터나 제한은 모든 제출 결과에 영향을 줍니다. 공개 후 수정했다면 기존 제출을 어떻게 처리할지 담당자와 확인하세요.
</warning>
