# 온라인 저지 문제 출제

학생은 기본 문제를 만들 수 있고, 교사·관리자는 고급 채점 설정과 대규모 테스트 도구를 추가로 사용할 수 있습니다. 문제를 처음 만들 때는 제목만 입력한 뒤 편집 화면에서 내용을 완성합니다.

## 기본 문제 정보

- 제목
- 시간 제한과 메모리 제한
- C, C++, Python, Rust 중 허용 언어
- 태그
- 문제 설명: 구조화된 편집기 또는 Markdown 원문과 미리보기
- 입력·출력 예제와 선택 설명
- 공개 여부
- 문제 설명에 사용할 자료 파일

공개 전에는 테스트가 하나 이상 등록되어야 실제 제출을 받을 수 있습니다. 비공개 상태에서 충분히 검증한 뒤 **문제 공개**를 켜세요.

## 역할별 기본 한도

한도는 문제를 출제할 때만 적용됩니다. 한도를 높이려면 문의하세요.

| 수준 | 시간 제한 | 메모리 제한 | 테스트 수 | 테스트 ZIP | 총 채점 시간 |
|---|---:|---:|---:|---:|---:|
| 학생 | 2,000ms | 128MB | 20개 | 20MB | 300초 |
| 교사 | 5,000ms | 256MB | 100개 | 100MB | 300초 |
| 관리자 | 60,000ms | 1GB | 제한 없음 | 128MB | 제한 없음 |

## 테스트케이스

테스트 관리에서 `X.in`과 `X.out` 쌍이 든 ZIP을 올리거나 입력·출력을 직접 작성합니다. 추가·수정·삭제는 임시 상태로 모였다가 **저장**할 때 함께 반영됩니다. 저장하지 않고 나가면 변경이 사라집니다.

## checker

기본 checker는 토큰 비교 `wcmp`입니다. 필요에 따라 다음 내장 채점기를 선택할 수 있습니다.

- `ncmp`: 64비트 정수 수열
- `rcmp4`, `rcmp6`, `rcmp9`: 각각 1e-4, 1e-6, 1e-9 오차의 실수 비교
- `fcmp`: 줄 단위 완전 일치
- `lcmp`: 줄 단위 토큰 비교
- `yesno`, `nyesno`: YES/NO 답 비교
- `hcmp`: 자릿수 제한이 없는 큰 정수 비교

고급 권한이 있으면 사용자 작성 checker 파일을 올려 내장 채점기 대신 사용할 수 있습니다.

## generator·정답 코드·validator

- **generator:** `testlib.h`를 사용하는 C/C++ 코드와 줄별 인자를 실행해 `gen/N.in` 테스트 입력 생성
- **정답 코드:** 모든 입력에 실행해 예상 `.out` 파일을 다시 생성
- **validator:** `testlib.h` 기반 C/C++ 코드로 모든 테스트 입력 검증

각 코드는 파일로 올리거나 화면에서 직접 작성할 수 있습니다. 컴파일과 실행 결과를 확인한 뒤 적용하세요. **초기화**는 모든 테스트 데이터와 generator, validator, 정답 코드를 삭제합니다.

## 비공개 접근 권한

비공개 문제를 함께 검토할 사용자를 선택하면 그 사용자는 공개 전에도 문제를 열람하고 편집할 수 있습니다.

## 공개 전 점검

1. 허용 언어마다 대표 정답과 오답을 제출합니다.
2. 예제와 실제 테스트의 형식이 같은지 확인합니다.
3. 시간·메모리 제한이 합리적인지 확인합니다.
4. checker, 정답 코드와 validator 오류가 없는지 확인합니다.
5. 공개 후 수정했다면 기존 제출 결과에 미치는 영향을 확인합니다.
