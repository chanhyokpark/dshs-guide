# 온라인 저지

온라인 저지에서는 프로그래밍 문제를 풀고 자동 채점 결과를 확인합니다. 학부모는 사용할 수 없고, 졸업생은 등록 후 기록을 읽을 수 있지만 새 코드를 제출할 수 없습니다.

## 문제 풀기

1. **온라인 저지 > 문제**로 이동합니다.
2. 제목, 번호, 태그 또는 해결 상태로 문제를 찾습니다.
3. 설명, 입력·출력과 제한을 읽습니다.
4. C, C++, Python 또는 Rust 중 허용된 언어를 선택합니다.
5. 코드를 작성해 제출하고 채점 결과를 확인합니다.

다른 사용자의 코드는 해당 문제를 해결한 뒤에만 볼 수 있습니다. 오류가 나면 컴파일 메시지, 실행 시간, 입력·출력 형식을 차례로 확인하세요.

## 문제 모음

필요한 문제를 문제 모음으로 구성해 연습 순서를 관리할 수 있습니다. 공개 범위와 포함된 문제를 확인한 뒤 공유하세요.

기본 문제 출제와 교사·관리자의 고급 출제는 [](online-judge-authoring.md)을 참고하세요.
