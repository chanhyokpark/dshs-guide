# 온라인 저지 사용

온라인 저지는 프로그래밍 문제를 읽고 코드를 제출해 자동 채점 결과를 확인하는 기능입니다. 학생, 교사와 관리자가 사용할 수 있으며 학부모에게는 메뉴가 제공되지 않습니다.

## 처음 등록하기

온라인 저지를 처음 열면 등록 화면에서 사용 범위를 확인하고 계정을 활성화합니다. 등록 후에도 학교 계정의 역할과 개별 제한에 따라 제출·출제·고급 기능 권한이 달라집니다.

| 역할 | 문제 열람 | 코드 제출 | 문제 출제 | 고급 출제 |
|---|---:|---:|---:|---:|
| 학생 | 가능 | 가능 | 기본 기능 | 불가 |
| 교사 | 가능 | 가능 | 가능 | 가능 |
| 관리자 | 가능 | 가능 | 가능 | 가능·태그 관리 |
| 학부모 | 불가 | 불가 | 불가 | 불가 |

## 문제 찾기

문제 목록에서 제목 또는 번호를 검색하고 태그를 조합해 찾습니다. 해결 상태는 다음과 같이 표시됩니다.

- 해결: 하나 이상의 제출이 **맞았습니다** 판정
- 시도: 제출했지만 아직 해결하지 못함
- 미시도: 제출 기록 없음

비공개 문제는 작성자, 접근 권한을 받은 사용자와 관리자 등 허용된 계정에만 보입니다. 관리자는 태그 관리에서 새 태그를 만들거나 이름을 바꾸고 삭제할 수 있습니다.

## 코드 제출

1. 문제의 설명, 입력·출력, 예제, 시간·메모리 제한과 허용 언어를 읽습니다.
2. **C, C++, Python, Rust** 중 허용된 언어를 선택합니다.
3. 편집기에 코드를 작성하고 제출합니다. 마지막으로 고른 언어는 다음 문제에서도 기본값으로 사용됩니다.
4. 실시간 채점 진행과 최종 판정을 확인합니다.

주요 판정은 맞았습니다, 틀렸습니다, 시간 초과, 메모리 초과, 런타임 에러, 컴파일 에러와 채점 실패입니다. 상세 화면에서 컴파일 메시지, 테스트별 실행 시간·메모리와 결과를 확인할 수 있습니다. 문제 화면 아래에는 해당 문제에 대한 내 제출 이력이 표시됩니다.

## 전체 제출 현황

**제출 현황**에서 문제 번호, 제출자와 내 제출만 보기 조건을 적용합니다. 다른 사용자를 고르는 기능은 권한이 있는 계정에만 나타납니다. 제출 코드와 상세 결과는 본인, 문제 작성자·편집자 또는 관리 권한 등 서버가 허용한 경우에만 열립니다.

## 문제집

문제집 목록에서 제목·설명을 검색하고 새 문제집을 만들 수 있습니다. 문제집 소유자는 다음을 할 수 있습니다.

- 제목과 설명 수정
- 제목 또는 `#문제번호`로 문제 검색 후 추가
- 문제의 위·아래 순서 변경
- 문제 제거와 목록 저장
- 문제집 삭제

문제집을 연 학생은 각 문제의 해결·시도 상태를 한 표에서 확인하고 순서대로 이동할 수 있습니다.

## 문제 출제

학생도 기본 출제 권한으로 문제를 만들 수 있습니다. 교사·관리자의 테스트 생성기, 검증기와 채점기 등 고급 기능은 [](online-judge-authoring.md)을 참고하세요.
