# 관리자 기능

관리자는 모든 교사 기능과 함께 사용자, 신청 일정과 전체 게시판·그룹을 운영합니다. 관리자 메뉴에는 사용자 관리, 장소 신청 관리와 기숙사 신청 관리가 표시됩니다. 게시판·그룹 전체 관리 화면은 현재 메뉴에서 숨겨져 있지만 새 관리자 기능으로 제공됩니다.

- [](admin-users.md): 계정과 사용자 명단
- [](admin-operations.md): 자습 좌석·기숙사 신청 운영
- [](admin-content.md): 게시판·그룹 전체 운영

<warning>
삭제, 벌점 초기화, 신청 비활성화·정리와 소유권 이전은 많은 자료에 영향을 줍니다. 경고창의 대상 수, 날짜, UID와 되돌릴 수 있는지 여부를 확인하세요.
</warning>
