# 운영 자료 내보내기

교사 홈과 학생 목록에서 날짜별 운영 자료를 Excel 형식으로 내려받습니다.

## 교사 홈 자료

- 오늘 자습 좌석
- 오늘 외출·특별실 신청
- 오늘 상·벌점 기록
- 활성화된 경우 오늘 또는 내일 기숙사 신청

신청 날짜가 열리지 않은 기숙사 버튼은 비활성화됩니다.

## 학생 목록 자료

[](query-students.md)의 현재 검색 결과를 내려받으면 학번, 이름과 화면에 제공되는 학생 정보가 포함됩니다.

다운로드가 시작되지 않으면 새 탭·팝업 차단과 브라우저 다운로드 권한을 확인하세요. 파일에는 학교생활 정보가 포함될 수 있으므로 개인 메신저나 공개 드라이브에 올리지 말고 사용 후 학교 방침에 따라 폐기하세요.
