# 상·벌점 부여와 취소

교사와 관리자는 한 명 또는 여러 학생에게 같은 상·벌점을 부여하고 기록 일부를 취소할 수 있습니다. 현재 상점 합계 하한은 **-20점**이며 등록된 기준표는 [](penalty-rules.md)에 있습니다.

## 대상 선택

**대상 선택**을 열어 세 방식 중 하나를 사용합니다.

### 목록

![학년·반 목록에서 대상 선택](Screenshot 2025-03-06 at 5.20.16 PM.png)
{width="300" thumbnail="true"}

학년과 반을 선택하고 학생을 체크합니다. 반에서 `*`를 선택하면 해당 학년 전체가 표시됩니다. **모두 선택**은 현재 필터 결과만 선택하며, 하단 **초기화**는 지금까지 고른 전체 대상을 지웁니다.

### 직접 입력

![학번·이름 직접 입력](Screenshot 2025-03-06 at 5.24.32 PM.png)
{width="300" thumbnail="true"}

학번 또는 이름을 입력하고 Enter를 눌러 차례로 추가합니다. 동명이인은 학번으로 고르는 것이 안전합니다.

### 검색

![학생 검색](Screenshot 2025-03-06 at 5.25.54 PM.png)
{width="300" thumbnail="true"}

학번·이름 검색 결과에서 여러 학생을 선택합니다.

## 사유와 점수

- 즐겨찾기 탭에서 자주 쓰는 항목 선택
- 목록에서 사유 또는 점수로 검색
- 직접 입력에서 임의의 사유와 숫자 입력

벌점은 양수, 상점은 음수로 입력합니다. 같은 사유라면 여러 학생을 한 번에 선택해 기록을 일관되게 남길 수 있습니다.

## 확인 후 부여

1. 대상과 사유를 고릅니다.
2. **미리보기 표시**를 켜 각 학생의 변경 전·후 점수를 확인합니다.
3. **벌점 부여**를 누릅니다.
4. 확인 창에서 인원, 사유와 점수를 다시 보고 확정합니다.
5. 성공 결과를 확인합니다.

상점 한도 등으로 일부 대상에 적용할 수 없으면 오류 대상을 확인하고 무조건 다시 누르지 마세요.

## 기록 조회와 취소

**벌점 기록**에서 최근 기록을 보고 학번·이름으로 검색합니다. 기본 목록에는 최근 **60개** 기록만 표시되므로 오래된 기록은 반드시 검색하세요.

1. 취소할 기록을 엽니다.
2. 한 번에 여러 학생에게 부여된 기록이면 취소할 학생만 체크합니다.
3. 취소 후 점수 변화를 확인합니다.
4. **벌점 취소**를 누릅니다.

취소는 선택한 학생의 해당 기록만 되돌립니다. 사유를 고쳐야 하는 경우 잘못된 기록을 취소하고 올바른 내용으로 새로 부여합니다.

## 기준 도달 알림

학생이 20·30·40·50·60점 기준에 도달하면 설정에 따라 메시지를 받을 수 있습니다. <ui-path>설정 | 알림 | 벌점 초과 메시지</ui-path>는 교사·관리자에게만 보이며 기본값은 꺼짐입니다.
