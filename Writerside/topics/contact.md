# 문의와 문제 제보

계정 등록, 로그인, 잘못된 학교생활 기록 또는 서비스 오류로 도움이 필요하면 [DSHS.APP 문의 페이지](https://dshs.app/contact)를 이용하세요.

1. 문의 페이지의 사람 확인 절차를 완료합니다.
2. **문의 이메일 보기**를 누릅니다.
3. 표시된 이메일 주소로 계정 ID, 발생 시각, 사용 기기·브라우저와 문제를 재현하는 순서를 보냅니다.

비밀번호, 이메일 인증 코드, 패스키 정보와 학부모 인증 코드는 보내지 마세요. 학생 정보가 포함된 화면 캡처는 꼭 필요한 범위만 남기고 다른 학생의 개인정보를 가린 뒤 첨부하세요.

문서 설명 자체가 잘못되었다면 [가이드 GitHub 저장소](https://github.com/chanhyokpark/dshs-guide)에 이슈를 등록할 수 있습니다.
