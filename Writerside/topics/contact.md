# 문의

문제가 해결되지 않으면 웹사이트의 문의 화면을 사용합니다.

## 문의 전 확인

- 앱 또는 브라우저를 최신 버전으로 업데이트
- 로그아웃 후 다시 로그인
- 다른 네트워크에서 재시도
- [](role-access.md)에서 계정 역할의 기능인지 확인

## 문의하기

1. **문의** 화면을 엽니다.
2. 사람 확인 절차를 완료합니다.
3. 화면에 표시된 연락처로 문의합니다.
4. 계정 역할, 기기·운영체제, 발생 시각, 화면과 재현 순서를 적습니다.

스크린샷을 첨부할 때는 학생 이름, 학번, 이메일, 인증 코드와 메시지 내용을 가리세요.

<warning>
비밀번호, 패스키, 이메일 인증 코드, 학부모 접근 코드는 문의 내용에 포함하지 마세요.
</warning>
