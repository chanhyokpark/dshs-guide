# 학생 목록과 상세 정보

학생 목록에서는 학번·이름으로 학생을 찾고 학번, 이름 또는 총 벌점 기준으로 정렬합니다.

## 검색

검색창에 다음 형식을 사용할 수 있습니다.

- `1`: 1학년
- `23`: 2학년 3반
- `3101`: 학번 3101
- 이름: 해당 이름의 학생
- `*`: 전체 학생

쉼표는 조건을 함께 만족하는 검색, 공백은 여러 후보 중 하나를 찾는 검색에 사용할 수 있습니다. 예를 들어 `12 3101`은 1학년 2반 학생 또는 3101 학생을 찾는 방식으로 사용할 수 있습니다.

정렬 메뉴에서 학번, 이름 또는 총 벌점과 오름·내림차순을 고릅니다. 결과는 페이지 단위로 이동합니다.

## 학생 상세

학생 행을 누르면 다음 정보가 표시됩니다.

- 받은 벌점·상점, 유효 점수와 도달 기준
- 오늘 신청한 자습 좌석과 좌석 화면 이동
- 활성화된 외출 신청
- 승인 대기 중 외출 신청

**기록 보기**로 해당 학생의 상·벌점 기록을 검색하고, **벌점 부여**로 학생이 선택된 부여 화면을 엽니다.

## 내보내기

현재 검색 결과를 Excel 파일로 내려받을 수 있습니다. 검색·정렬 조건과 포함 학생을 확인한 뒤 내보내고, 개인정보가 포함된 파일은 담당자만 접근할 수 있는 위치에 보관하세요.
