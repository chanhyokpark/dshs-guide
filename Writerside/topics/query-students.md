# 교사 홈·학생 조회·내보내기

교사 홈의 빠른 검색과 학생 목록에서 담당 업무에 필요한 학생을 찾습니다.

## 학생 찾기

1. 교사 홈 또는 **학생 조회**로 이동합니다.
2. 이름, 학번 등 화면에서 제공하는 조건을 입력합니다.
3. 검색 결과에서 학생을 선택합니다.
4. 권한이 허용한 학교생활 기록을 확인합니다.

검색 결과가 너무 많으면 학년·반 등 추가 조건을 적용하세요. 조회한 개인정보는 담당 업무에 필요한 범위에서만 사용합니다.

## 목록 내보내기 {id="export"}

1. 학생 목록에서 필요한 검색·필터를 적용합니다.
2. **내보내기**를 선택합니다.
3. 포함할 항목과 파일 형식을 확인합니다.
4. 파일을 내려받아 행 수와 항목을 확인합니다.

학교생활 메뉴의 자습, 외출, 상·벌점 화면에도 해당 업무용 내보내기가 제공될 수 있습니다.

<warning>
내보낸 파일은 개인 기기에 오래 보관하지 말고, 업무가 끝나면 학교의 개인정보 처리 기준에 따라 삭제하세요.
</warning>
