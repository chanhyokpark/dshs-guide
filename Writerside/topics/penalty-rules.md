# 상·벌점 확인과 현재 기준

상·벌점 화면은 받은 벌점, 받은 상점, 합산한 유효 점수, 연도별 변화와 개별 기록을 보여 줍니다. 양수는 벌점이고 음수는 상점입니다.

## 기록 확인

1. **벌점 확인**을 엽니다.
2. 현재 학년 또는 과거 학년 탭을 선택합니다. 아직 재학하지 않은 이후 학년은 열 수 없습니다.
3. 그래프에서 점수 변화를 확인합니다.
4. 월별 기록에서 부여일, 사유, 점수와 부여자를 확인합니다.

학부모는 화면 위에서 연결 학생을 선택해 같은 정보를 읽기 전용으로 확인합니다. 기록 내용이 실제 상황과 다르면 해당 기록을 부여한 교사 또는 학교 담당자에게 문의하세요.

## 현재 합산·징계 값

- 한 기간에 반영되는 상점의 한도는 **-20점**입니다.
- **20점:** 경고
- **30점:** 청소 3일
- **40점:** 청소/퇴사 5일
- **50점:** 청소/퇴사 10일
- **60점:** 청소/퇴사 1달

기준에 도달한 뒤 상점을 받아 총 벌점이 기준 밑으로 내려가더라도 징계를 받을 수 있습니다.
