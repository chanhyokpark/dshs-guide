# 단체 메시지

교사와 관리자는 여러 학생에게 각각의 1:1 메시지를 한 번에 보낼 수 있습니다.

## 직접 대상 선택

1. **단체 메시지**에서 새 발송을 만듭니다.
2. 학생을 검색해 수신자를 추가합니다.
3. 내용과 첨부파일을 입력합니다.
4. 수신자 수와 내용을 미리 확인합니다.
5. 즉시 보내거나 예약 시간을 지정합니다.

예약 발송 시간은 30분 단위로 선택합니다.

## Google 스프레드시트로 작성

1. 제공된 형식에 맞춰 수신자와 메시지 내용을 작성합니다.
2. 스프레드시트를 선택하고 미리보기를 실행합니다.
3. 오류가 표시된 행을 모두 수정합니다.
4. 전체 검증을 통과한 뒤 발송합니다.

행 하나라도 유효하지 않으면 전체 발송이 진행되지 않습니다. 일부만 보낼 필요가 있다면 잘못된 행을 제거한 별도 자료를 사용하세요.

발송 기록에서 상태를 확인하고, 아직 처리 가능한 발송은 삭제할 수 있습니다.

<warning>
단체 메시지는 수신자마다 개별 대화로 전달됩니다. 개인정보가 다른 수신자의 본문에 섞이지 않았는지 미리보기에서 확인하세요.
</warning>
