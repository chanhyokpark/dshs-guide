# 학생 홈

학생 홈은 자주 확인하는 정보를 카드와 바로가기로 모아 보여 줍니다.

![기존 iOS 앱 홈 화면](Screenshot 2025-01-17 at 1.48.53 PM.png)

앱과 웹의 배치는 다를 수 있지만 표시되는 데이터는 같은 계정을 기준으로 합니다.

## 홈에 표시되는 정보

- **상·벌점:** 받은 벌점, 받은 상점과 합산한 유효 점수
- **다음 급식:** 현재 시각을 기준으로 다음 아침·점심·저녁 메뉴
- **자습 신청:** 오늘 좌석과 신청 가능한 다음 날짜의 좌석 또는 신청 상태
- **과제:** 해야 할 과제와 마감이 가까운 과제 요약
- **최근 메시지:** 새로 도착한 대화 일부
- **즐겨찾기 게시판:** 별표로 즐겨찾기한 게시판 바로가기
- **공지·광고:** 운영 공지, 업데이트 또는 게시판 광고 배너

카드를 누르면 해당 상세 화면으로 이동합니다. 화면에 새 버전 안내가 나오면 앱 또는 웹을 새로고침하거나 안내된 버전으로 업데이트하세요.

## 빠른 실행

학생 홈에서는 외출·특별실 신청, 기숙사 신청, 설정, 급식과 도서관 바코드 등을 빠르게 열 수 있습니다. 메뉴가 보이지 않으면 왼쪽 사이드바 또는 모바일 메뉴를 여세요.

## 공통 상단 메뉴

- 종 모양 알림 메뉴를 열면 알림이 읽음 처리됩니다. **모두 삭제**는 현재 알림 목록을 비웁니다.
- 테마는 시스템 설정, 밝게, 어둡게 중 선택할 수 있습니다.
- 사용자 메뉴에서 프로필, 설정과 로그아웃으로 이동합니다.
