# 웹 화면과 홈

로그인하면 계정 역할에 맞는 홈이 열립니다. 왼쪽 메뉴 또는 모바일 하단 메뉴에서 기능으로 이동하고, 상단의 알림·계정 메뉴에서 새 소식과 설정을 확인합니다.

## 학생 홈

학생 홈에는 즐겨찾는 게시판, 공지·광고, 과제, 최근 메시지, 상·벌점, 급식, 자습 신청 현황과 빠른 링크가 표시될 수 있습니다. 카드가 보이지 않으면 해당 기능을 사용할 권한이나 표시할 데이터가 없는지 확인하세요.

## 학부모 홈

학부모 홈에서는 먼저 연결된 학생을 선택합니다. 선택한 학생의 상·벌점, 급식, 자습과 외출 현황을 읽기 전용으로 확인할 수 있습니다. 게시판과 메시지는 학부모 계정의 권한으로 사용합니다.

## 교사·관리자·졸업생

- 교사와 관리자는 교사용 홈 또는 운영 화면으로 이동합니다.
- 졸업생은 허용된 게시판을 중심으로 시작합니다.
- 메뉴는 화면 크기와 계정 권한에 따라 접히거나 일부만 표시됩니다.

<tip>
원하는 메뉴가 없으면 [](role-access.md)에서 역할별 범위를 먼저 확인하세요. 권한이 있어야 하는데 보이지 않는다면 로그아웃 후 다시 로그인한 다음 문의하세요.
</tip>
