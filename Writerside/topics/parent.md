# 학부모 가이드

학부모 계정은 자녀의 학번, 이름과 **학부모 인증 코드**로 등록합니다. 이 코드는 과거의 별도 벌점 조회 코드가 아니라 현재 학부모 계정 등록과 학생 추가에 사용됩니다.

## 처음 시작하기

1. [](parent-registration.md)에 따라 계정을 등록합니다.
2. 자녀가 여러 명이면 같은 등록 과정이나 <ui-path>설정 | 학생 관리</ui-path>에서 추가합니다.
3. 홈 상단의 학생 선택 메뉴로 현재 보고 있는 자녀를 확인합니다.

## 사용할 수 있는 기능

- [](parent-views.md): 연결 학생의 자습, 외출·특별실, 상·벌점 확인
- [](meal.md): 날짜별 급식과 알레르기 표시
- [](parent-communication.md): 허용된 게시판·그룹과 1:1 메시지
- [](parent-settings.md): 연결 학생 추가·해제, 로그인 이메일, 패스키와 알림

학부모의 학교생활 화면은 읽기 전용입니다. 학생 대신 자습·기숙사·외출을 신청하거나 취소할 수 없으며, 과제 센터·온라인 저지·학교 Google 연결·학생 프로필 수정 기능은 제공되지 않습니다.
