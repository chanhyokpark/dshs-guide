# 학부모

학부모 계정은 학생의 학번·이름과 학교에서 안내한 접근 코드로 등록합니다. 한 계정에 연결된 학생이 여러 명이면 홈에서 학생을 바꿔 확인할 수 있습니다.

## 처음 등록하기

1. 로그인 화면에서 **학부모 등록**을 선택합니다.
2. 학생의 학번과 이름을 입력합니다.
3. 학부모 접근 코드를 입력합니다.
4. 이메일 인증을 완료합니다.
5. 필요하면 패스키를 등록합니다.

## 연결 학생 관리

학부모 설정에서 새 학생을 연결하거나 기존 연결 상태를 확인합니다. 추가 연결에도 해당 학생의 올바른 접근 코드가 필요합니다.

접근 코드가 노출되었거나 연결 대상이 잘못되었다면 코드를 다시 사용하지 말고 학교 담당자에게 문의하세요.

학부모가 확인할 수 있는 화면은 [](parent-views.md)을 참고하세요.
