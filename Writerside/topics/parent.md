# 학부모 가이드

학부모는 개인 로그인 **Account**에 자녀별 **학부모 User**를 연결해 DSHS.APP을 사용합니다. `parent-...@dshs.app` 등록 주소는 학교가 자녀의 학부모 User를 지정하기 위해 발급하는 값이며, 실제 로그인에는 등록한 개인 이메일을 사용합니다.

## 처음 시작하기

1. 학교에서 자녀의 학부모 등록 주소와 8자리 인증코드를 받습니다.
2. [](parent-registration.md)에 따라 새 계정을 만들거나 기존 계정에 학부모 사용자를 연결합니다.
3. 자녀가 여러 명이면 각 자녀의 주소와 코드로 학부모 사용자를 같은 계정에 하나씩 추가합니다.
4. 홈 상단 **사용자 전환**에서 현재 `학생이름 학부모`를 확인합니다.

## 사용할 수 있는 기능

- [](parent-views.md): 현재 학부모 User에 연결된 학생의 자습, 외출·특별실, 상·벌점 확인
- [](meal.md): 날짜별 급식과 알레르기 표시
- [](parent-communication.md): 허용된 게시판·그룹과 1:1 메시지
- [](parent-settings.md): 자녀별 User 전환·추가, 로그인 이메일, 패스키, 로그인 기기와 알림

학부모의 학교생활 화면은 읽기 전용입니다. 학생 대신 자습·기숙사·외출을 신청하거나 취소할 수 없으며, 과제 센터·온라인 저지·학교 Google 연결·학생 프로필 수정 기능은 제공되지 않습니다.
